# 架构变更记录

> 记历史：**现象 → 定论**。现状看 `当前项目架构.md`，取舍看 `决策记录.md`，教训看 `踩坑清单.md`。
> 写法：只记**最终落地的做法**；被回退的尝试最多留一行（"曾试 X，已回退，原因 Y"），
> 不给每个错误写长文。写之前先确认行为通过 —— 回退时这份记录要重写第二遍。

> **结构**：§1 是**定论索引**（一条一行，链到归档全文），§2 是**最近 3 轮全文**。
> 更早的每一轮在 `架构变更记录/` 目录里按 `YYYY-MM-<轮名>.md` 分卷（冻结不改）。
> 归档只搬家不改写：分卷前的每一节都在，找一条旧定论用 §1 的索引，或直接在该目录里搜索。
> 分卷规则：主文件留最近 3 轮，其余每轮一份；一条定论只在一个归档文件里，主文件不重复正文。
> 文件名不带空格（`/` 写成 `、`），这样链接可以直接写中文路径。

# 回声铃兰蓄能速射：普通关卡自带共鸣，连接与爆发看得见

> 用户指出铃兰离开温室后特点变弱，并要求共鸣改为加快攻速。确认后选择“接力蓄能、短时爆发”；
> 继续制作时再次指出玩家几乎感知不到特性，因此补齐种植预览、常驻状态提示与明显的整组圆环。

## 现象 → 定论

**1. 普通关卡也有可积累的共鸣。** 相邻铃兰每发起一轮有限接力蓄一格，三轮后整组进入共鸣，
最后一声之后持续六秒、冷却进度以两倍速度推进。单株不靠独唱蓄能；爆发期间不继续累积下一轮。
每轮每株仍只发一枚原伤害声波，没有另加伤害更低的额外齐射。连接新成员不跳过旧成员冷却，
蓄能按组内最低值合并；接入已共鸣的组可继承其原期限，不能延长期限。

**2. 温室借攻速，不再借子弹。** `ResonanceMechanic` 每 tick 给与共鸣行相交的连通组授予
当前 tick 的攻速倍率；离行、断开或机制移除即停止借来的加速，自身蓄出的共鸣仍按原期限继续。
两种倍率取较大者，不相乘。机制编辑器以 `plant_rate` 替代旧的额外齐射间隔与伤害字段；
行移动、僵尸加速、状态同步与存档时钟保留。

**3. 冷却只消费当下速度。** 每株保存剩余工作量与接力尾声期限，每 tick 只推进一次；共鸣在
冷却中途开始或结束也只影响之后的进度。存档包含小数冷却、蓄能、自身共鸣期限与待发声波；
旧存档的 `readyAt` 与已安排声波仍可读取，未安排的新额外齐射不再产生。

**4. 能力要在棋盘上讲清楚。** `EchoLilyLinks` 是植物自己的渲染伴侣，所有关卡都可显示金线；
拿着卡移到邻格时先预览连接。由服务端射击状态触发连线光点，蓄能三格灯在 GUI 层画，
不会被叶片盖住；每个连通组显示一份“接力蓄能 / 共鸣速射”提示，独株提示相邻种植可接力。
攻击状态带蓄能片段别名，开火时不会把灯清成零。共鸣期间圆环常亮并缓慢呼吸，待机动作更快；
顶行提示遇到卡栏时侧移。圆环纹理读取粒子定义，不另造内容 id 到纹理的映射。

## 验证与边界

- 有限环、斜邻隔离、待发声波与共鸣行续档、减速乘算，以及普通关卡蓄能爆发全部通过。
  冷却中途加入、移除共鸣机制不会突然补发；普通共鸣续档后逐 tick 比较后续射击时刻与音调一致。
  根株与响应株开火期间下发的状态均保留蓄能。
- 实际内置关卡、普通难度、真实阳光成本与卡槽冷却，固定种子 17 / 20261001 / 81 均胜利，
  战斗时间分别 192.9 / 168.6 / 160.1 秒，全部 35 只敌人参与；总花费均 1450 阳光，
  峰值存活敌人为 5 / 6 / 7。该结论不推到未校准的高难度。

  一次 1920×1080、GUI 缩放 2 的连续截图检查：`.smoke/echo-feedback/frame_120.png` 可见
  蓄能与独唱提示，`frame_240.png` / `frame_360.png` 可见行外网络也亮起整组共鸣圆环。

# 原创回声铃兰与回声温室：有限接力、移动共鸣行

> 用户要求新增原创植物、原创机制，并能在另一个有原创机制的关卡里使用它，允许 GPT Image 作画。
> 盘点后确认已有普通射击、待发队列、机制状态同步与小游戏入口，尚无邻接声波网络；用户确认
> “回声铃兰 / 回声温室”的方向后继续实施。复用草坪舞台，原创内容集中在植物、美术与两种相互作用的机制。

## 现象 → 定论

**1. 相邻攻击不能靠“收到声波再发声波”无限递归。** `EchoRelayCapability` 一次按正交邻接求出
同阵营、存活且醒着的连通组，按最短距离安排每株一发声波。单株 40 点，连通组每株 60 点，
每跳延迟 8 tick；整组最后一株出声之后休息 180 tick。共享冷却封住环形连接和“接上一株立即再打”的捷径。
只有成员前方出现地面敌人才自动发起；弹丸按普通护甲与单次命中规则结算。默认值进 `PvzceConstants`，
卡面价格和冷却从植物定义继承，没有再在卡槽中抄一份。能力同时支持停火、点名齐射、已许诺回声和续档。

**2. 共鸣行是一条带收益的危险车道。** `ResonanceMechanic` 从中间行起每 720 tick 向上移一行，
到顶后循环。该行敌方地面僵尸移动倍率 1.35；每 180 tick 给与该行相交的铃兰网络安排一次
每株 30 点的额外齐射，同一连通组在这一拍只触发一次。额外拍点与普通冷却分开，组合减速时用倍率相乘，
离行后不会残留加速。时钟、行号、判定全归服务端；全量同步钩子保证暂停进场也拿到当前行，存档保存时钟。
普通难度下即 12 秒换行 / 3 秒额外拍点；两份机制周期不乘难度倍率，通用难度仍影响僵尸与出怪。

**3. 关卡先让玩家学会连接，再给日常使用。** `yard/minigame/echo_conservatory.json` 直接开放、
固定卡组、325 初始阳光，预置两株相连铃兰。五波共 35 只普通、路障、铁桶与旗帜僵尸，玩家仍付真实
阳光并等卡槽冷却。首通解锁回声铃兰并发金币；金色连线说明正交连接，绿色带、换行前黄色预告线、
底部行号与倒计时说明共鸣车道。HUD 百分比读取同步的机制配置，编辑器改加速倍率不会留下旧文案。

**4. GPT Image 源图与游戏资产都能追溯。** 使用内置生图工具生成透明的三铃、薄荷绿叶原创形象，
源图和提示词分别保存在 `tools/art/echo_lily.png`、`tools/art/echo_lily.prompt.txt`；
`tools/build_echo_lily.sh` 打包贴图、卡面与控制器，程序绘制声波、圆环并合成铃音。
`idle` 是缓慢呼吸，`shoot` / `echo` 是预备、弹起、过冲和归位，`resonate` 是幅度更大的出声动作。
服务器在片段结束时也回到 idle，使下一次相同攻击状态能重新播放。分类脚本把角色美术归入原创，
几何特效与合成音归入自产；没有复制或修改 `refer/`。
