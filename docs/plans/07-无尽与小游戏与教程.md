### 1.2 四条新无尽（草坪）

| id | 名字 | 棋盘 | 无尽时钟 | 变异 |
|---|---|---|---|---|
| `pvzce:yard/survival/endless_lawn_day` | 草坪无尽（白天） | 9×5 全草坪，割草机 5 行 | `pvzce:pool_endless`（复用；它只管节奏，不管棋盘） | 无 |
| `pvzce:yard/survival/endless_lawn_night` | 草坪无尽（黑夜） | 同上，但 `day_length 0 / night_length -1`，墓碑生长 | 同上 | 无 |
| `pvzce:yard/survival/mutation_lawn_day` | 草坪变异无尽（白天） | 9×5 全草坪 | `pvzce:mutation_endless` | `pvzce:mutation` 机制 |
| `pvzce:yard/survival/mutation_lawn_night` | 草坪变异无尽（黑夜） | 同上 + 夜 | `pvzce:mutation_endless` | 同上 |

实现：四条都加进 `server/level/EndlessLevels.java`（它已经是"代码构造关卡"的家），
照 `MutationLevels.build(...)` 的形状写；草坪版把 `scene` 换成 45 格 `pvzce:grass`、
`mechanics` 的 mower 换成 `MowerData` 默认（每行 `pvzce:lawn_mower`）。

**为什么复用两份 schedule**：`EndlessScheduleDef` 里的 `pool` 条目带 `water` 标记
（`EndlessScheduleDef.java:126,132`），而 `EndlessWaves.composition()` 会按它把生成的行
拆成水/陆两池（`EndlessWaves.java:144-167`）。草坪棋盘**没有水行**，
所以水僵尸会被分到空池子里 → **要么给草坪版加第三份 schedule，要么让 `EndlessWaves`
在没有水行时把水僵尸也放进陆地行**。
→ **选前者**：新加 `pvzce:lawn_endless`（陆生池 + 不做行拆分）与
`pvzce:lawn_mutation_endless` 两份 schedule，放在 `EndlessSchedules.java`。
这样"难度是数据"这条约定继续成立（`当前项目架构.md` §9）。

## 3. 变异教程关（批次 10）

`pvzce:yard/survival/mutation_tutorial`，名字 **"变异教程"**。

### 3.1 先做的一件基础设施：关卡固定变异

`todo.md` 第 11 条早就记着"关卡还不能固定出某个变异"。现在必须做，因为教程关要按剧本
逐个演示变异。

`common/level/mutation/MutationMechanic.java` 现在是 `MechanicData.Empty`，改成带数据：

```json
{ "type": "pvzce:mutation",
  "random": false,
  "schedule": [
    { "id": "pvzce:slot_replace", "at_tick": 900 },
    { "id": "pvzce:sun_rate",     "at_tick": 2400 },
    { "id": "pvzce:bowling_nut",  "at_tick": 4200 },
    { "id": "pvzce:conveyor",     "at_tick": 6000 }
  ] }
```

- `random: false` 表示**这一关不掷骰**，只按 `schedule` 到点加；
- `at_tick` 是关卡内 tick；`schedule` 走 `MutationManager` 的一条独立时钟，
  与"随机到达"那条并列（两者可同时存在，`random: true` 时也允许 `schedule`）；
- **`schedule` 的内容要进存档**（`level.dat` 的 `Mutations` 块加一个 `Fired` 位集），
  否则续档会把已经演过的变异再演一遍。

### 3.2 关卡剧本（用户要求：豌豆酱引导，非无尽，变异固定）

- 9×5 白天草坪，`background1`，音乐 `grasswood`；
- 固定卡组：豌豆射手 / 向日葵 / 坚果墙 / 樱桃炸弹（4 张，够用且不至于淹没教学）；
- 波次：**6 波，全 `small`**，压力很低（每波 1~2 只普通僵尸），
  目的是"让玩家有空读台词"；
- **没有 `pvzce:endless` 机制**，所以打完 6 波就赢（用户明确"这一关不是无尽"）；
- `dialogue` 用 `pvzce:pea_chan`（豌豆酱，就是用户说的 peachan）：
  台词风格照 1-1~1-10（`1_9.json` 的四句是现成的语气样本：
  短句、自称"咱"、有"不过不过！"这种口语）；
- `hints` 每条都写明确的 `duration_ticks`（缺陷 9 的纪律）。

台词脚本（**现在就写**，用户已批准"教程关你写台词"）：

| 时机 | 角色 | 台词（草稿，落地时再润色） |
|---|---|---|
| 开场 | 豌豆酱 happy | "欢迎来到变异教程！这一关不长，咱带你认认变异是什么。" |
| 开场 2 | 豌豆酱 smile | "变异就是——打着打着，规则突然变了一下。别慌，咱陪你。" |
| `slot_replace` 到达 | 豌豆酱 surprised | "看卡槽！卡变了！这叫**卡槽变异**，你的卡会被换成同类型的别的植物。" |
| `sun_rate` 到达 | 豌豆酱 tsundere | "阳光变快了……或者变慢了。这种只改数字的，叫**数值变异**。" |
| `bowling_nut` 到达 | 豌豆酱 happy | "坚果变保龄球了！这种把玩法整个换掉的，叫**小游戏变异**。" |
| `conveyor` 到达 | 豌豆酱 fierce | "卡槽变传送带了！注意——**铲子还在**，工具不会被传送带吃掉。" |
| 通关 | 豌豆酱 welcome | "学会了吧？真正的变异无尽里，这些是随机来的哦。" |

`dialogue` 只支持"进场前/通关后"两组（`LevelDialogue` 有 `lines` / `enter` / `exit`），
**没有"按 tick 触发的台词"**。所以要新增一小块：
`LevelDialogue` 加 `timed: [{at_tick, line}]`，客户端在关卡里按 tick 播放
（`DialogueOverlay` 已存在，只需要一个"排队播下一句"的入口）。
