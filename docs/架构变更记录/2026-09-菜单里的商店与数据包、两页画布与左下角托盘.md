# 菜单里的商店与数据包：改成有画布的两页，入口移出主菜单

> 用户报："这商店页面和数据包加载页面，挤在主页和菜单栏并列很难看，而且商店页面里面也非常难看。"

## 现象与根因

- **商店页**：三行 44 高的半透明灰条直接画在**模糊后的标题页截图**上，一格一张卡都没有。默认窗口
  GUI 只有 427x240，`walletY` 与 `noticeY` 在 120 附近撞车，**"金币 0"就压在第三行上**。
- **数据包页**：左列表只有一层 0.8 透明度的暗块（只有一个内置包时，那块暗块看起来像没画完），
  右栏详情文字**直接压在背景图上**，内容摘要的键值在窄窗口里互相撞。
- **共同根因**：这两页是**唯一两个直接在 GUI 单位里排版的页面**。游戏里其余有真正构图的界面
  （图鉴、选卡页、关卡列表）都在**固定画布**上构图再等比缩放到窗口，所以两页既没有面板也没有层次。
- **入口**：商店与数据包原本是标题页六个并列按钮里的第二、第三个。菜单一行是"你要做的事"，
  而这两页是"你进去看看再回来的地方"，形状本来就不对。

## 定论

1. **两页改成 800x600 原生画布**（`gui/layout/MenuPageCanvas`）：contain 缩放（`fit`），构图为
   标题条 + 木框面板（`seed_chooser_background` 九宫格，边 9/9/32/32）+ 页脚按钮；背景是标题页
   那张 `title_background` 压一层 22% 暗色，**不再要模糊底**（`blurredBackdrop()` 两页都关掉）。
   缩放与点击反算与 `AlmanacScreen` 同一套。
   - **控件不进画布**：列表与按钮仍是 GUI 单位（标签要随窗口字号），需要放进面板的控件用
     `Canvas.widgetAt` / `interiorX/Width/Bottom/Height` 换算——同一份换算只有一处，
     画出来的框与可点区域因此不可能分家。
2. **商店页**：标题条右侧钱包（金币图标 + 数字），下面一块木框面板，面板里一行一件商品
   （64 图标 + 名称 + 一句用途 + 价格/已拥有 N/M），行高 96。行仍走 `AbstractSelectionList`
   （滚动、裁剪、行几何都是现成的），购买与悬停由界面自己按**列表的几何**判定。
   - `gui.pvzce.shop.desc.*`：三句用途进语言文件；卡槽上限取 `PvzceConstants.MAX_SEED_SLOTS`、
     阳光铲返还取 `BuiltInBuffs.SUN_SHOVEL_REFUND`，**数字不在界面里写第二遍**。
3. **数据包页**：保留左列表 + 右详情，两块都上木框；详情在面板内边距以内排版（标题 / 类型行 /
   作者描述换行 / 内容摘要两列），底部两个按钮与页脚「返回」由 `widgetAt` 定位。
4. **入口移到标题页左下角的木托盘**：主菜单从六个按钮减到四个（开始游戏 / 模组列表 / 设置 / 退出），
   商店与数据包变成托盘里的两个**图标格子**（金币图标 / 种子包图标），木托盘用同一张九宫格。
   - **为什么只有图标**：默认窗口下菜单列左缘在 GUI x 74、玩家木牌到 x 146，左下角只剩约 66 宽，
     而"图标 + 两个汉字"的格子要约 100。名字改由 `HoverTip` 在悬停时给出（与卡槽条同一个通道）。
   - 版本号那行从底边左侧（被托盘占了）挪到**右下角**右对齐。

## 踩到的三个坑（都写进了 `踩坑清单.md`）

- **画布缩放的"可读性下限"是错的**：`MIN_SCALE = 0.55` 在默认窗口（需要 0.40）赢了 fit，
  于是整个画布顶到屏幕上方 45 单位，**标题条与页脚按钮直接被推出屏幕**。contain 画布的下限只能是 0。
- **别用字体行高去算固定版面**：托盘单元高度一度由 `fonts().body().lineHeight(scale)` 推出，
  而它是**设备像素**算完再除 GUI 缩放（scale 3 时为 14 而非 5），单元一下变成 90 高、第二个格子
  被裁掉。凡是要跟另一个常量对齐的尺寸就用常量。
- **冒烟截图不建目录**：`capturePath` 的父目录不存在时只打印一行 `failed to write screenshot`，
  没有异常、没有非零退出码。

## 判据

- `TitleScreenTrayTest`：两个格子的中心各自打开 `ShopScreen` / `PackScreen`；托盘右缘不超过菜单列
  左缘（就是把"格子压在开始游戏底下"那三次返工钉住的那条）；点托盘木头本身不开任何页。
- `GuiComponentsRegressionTest.listScrollOffsetIsTheClampedOneItDrawsWith`：
  `AbstractSelectionList.scrollOffset()` 返回的是**夹紧后**的偏移（商店的行命中测试读它）。
- 冒烟一次启动拍三页：`pvzce.smokePages=20:title,80:shop,150:packs` + `captureEvery=40`，
  产物 `.smoke/ui-after/s_30.png`（标题页托盘）、`s_110.png`（商店）、`s_150.png`（数据包）。
