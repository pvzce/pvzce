# 统一地表高度、泳池与桥上桥下基础（2026-10-04）

屋顶实体已经抬高，但特效仍携带平面坐标；泳池下沉只发生在客户端，叠放和命中读取另一套高度。
用户要求统一底层，并选择重叠通路通过“当前操作层”切换，接受近战按通路、弹道及爆炸按空间与障碍的规则。

- `SceneBoard` 统一地表格、基础材质、覆盖物、高度曲线与桥面厚度；屋顶和旧泳池导入同一模型。
  冰、弹坑和容器清除后恢复基础地表，初始桥面冰层遵守同一规则，屋顶不会被还原成零高度草地。
- `WorldPosition` 分开平面坐标与绝对高度，实体、效果、掉落物、磁吸装备和客户端伴随渲染共用投影。
  泳池高度进入服务端，去掉客户端补偿；旧泳池实体存档按高度差迁移，读取不改写传入 NBT。
- `LevelDef.surfaces` 描述稀疏通路，初始实体可以指定 surface；放置、铲除、手套、护理、瞄准等请求携带操作层。
  HUD 按钮与 PgUp/PgDn 切换、高亮当前层；相机反算鼠标落点使用该层地表，缺失格拒绝操作。
- 近战及通路查询保留地表归属；平射与抛掷按实际身体高度命中，线段连续检查基础地形与桥面，避免快速弹丸穿透。
  爆炸共用空间范围与遮挡查询，磁吸同样不能穿过桥面；协议升至 56，并更新线格式快照。
- 定向回归通过上下层独立种植/铲除/啃咬、平射、抛射拦截、爆炸遮挡、薄桥面、覆盖物恢复、泳池落地、
  旧档迁移、镜像选格与协议往返；既有 5-1～5-9 预置阵容结算回归仍通过。
  唯一一次 1920×1080 / GUI 2 冒烟在 `.smoke/scene-surfaces/`：`s_60.png` 为屋顶与桥面爆炸，
  `s_480.png` 为切到桥面后的高亮与下层遮挡；这是几何探针，复用既有材质，不是新增桥梁关卡美术。
  磁吸补充变更由真实转移与续档回归验证，没有第二次冒烟启动。

多层编辑控件、通路连接与正式桥梁关卡尚未制作，范围见 `todo.md`。
