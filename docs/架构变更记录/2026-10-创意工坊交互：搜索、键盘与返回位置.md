# 创意工坊交互：搜索、键盘与返回位置（2026-10-18）

内容浏览器只能按类型筛选，选择器每输入一个字都重建整页，翻页缺少边界与数量反馈；
输入弹窗无法直接回车，实际 Esc 路径又绕过保存与弹窗取消，创作时容易丢位置或丢草稿。

- 工作区与内容浏览器增加名称、命名空间、路径和草稿译名搜索；类型筛选显示当前类型，
  「全部」同时清除筛选与搜索。选择器仅有一个匹配项时支持回车选择，多项和空结果保持原页。
  搜索仅替换结果控件，保留输入框与焦点；列表显示页码、匹配数量和空结果提示，边界按钮禁用，内容区支持滚轮与滑动翻页。
- 工坊输入弹窗打开即接收键盘，回车与确定按钮共用接受行为。点击分发在回调前释放旧焦点，
  避免回调刚打开并聚焦的弹窗再次失焦，也使「清空」后可连续输入。
- 普通屏幕的 Esc 经过 `Screen.dispatchEscape`：模态弹窗先处理，关闭后移除并释放焦点；
  没有弹窗时执行各屏的关闭策略。工坊子配置返回进入前的位置，顶层退出保存草稿；无效数字阻止退出。
  编辑标题显示保存状态与中文配置路径，属性分组和子配置各自记忆页码。
- 小窗口能力卡提高可用区域，分页固定放在底栏，排序改为「前移 / 后移」并禁用边界，避免与翻页混淆或遮挡；
  紧凑内容卡改为左图右文，窄窗口不再为实体预览挤占表单宽度。高级数组编辑复用同一排序与删除入口，帧时长及输入错误随条目同步。
- 定向回归经过实际点击、字符、回车、Esc 和滚轮入口，检查创建、唯一匹配、译名搜索、无效数字、草稿保存和返回页码；
  小窗口测试固定 UI 倍率，确认实际逻辑尺寸为 427×240。唯一一次 1920×1080 / 2 倍 UI 冒烟在 `.smoke/workshop-ux/`：
  `ui_40.png` 为带搜索与分页的内容页，`ui_120.png` 为选择器，`ui_200.png` 为属性页，`ui_520.png` 为动画配置。
  子配置往返与小窗口遮挡由分发回归验证；截图没有覆盖触屏硬件手势。
