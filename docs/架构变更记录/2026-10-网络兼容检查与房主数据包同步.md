# 网络兼容检查与房主数据包同步（2026-10-31）

现象：TCP 和进场包依赖手工协议版本，加入房间还会因模组版本或素材差异直接拒绝，客人不能取得房主的数据包。

- 兼容检查改为实际注册网络包的 ID、方向、类型与递归 record 字段/枚举指纹；TCP 和局域网共用，删除关卡包版本字段与模组版本/整栈素材硬门槛。
- 房主开房时冻结已启用的外部包清单和文件；玩法数据包必须接受，表现资源包可选，创建页可强制全部。客人先选包、下载并校验，再挂载资源并安装服务端内容定义与标签，完成确认后才入场。
- 包按内容哈希判断差异、缓存和复用；下载采用逐块请求与响应，校验顺序、长度、哈希、路径及体积。会话栈保留房主顺序，刷新材质、语言、声音与字体，离开恢复本地内容并清临时目录，不覆盖本地包与启停配置。
- 包协商期间禁重复连接；取消/连接失败释放后台包状态并恢复本地服，未获准入场的连接关闭即释放席位。分层白名单保持不变，不分发可执行模组。
- 定向回归覆盖实际 TCP 握手、独立 JVM 额外注册包后的握手拒绝、独立 JVM 下载并挂载房主资源后战斗、旧本地包不被覆盖、缓存复用、可选与全部必须、禁用包不分发、坏哈希/乱序/越界压缩包拒绝，以及真实控件点击和缩放保留选择。日志 `.smoke/network-packs/targeted.log`、`ui-tests.log`、`final-targeted.log`。
- 游戏/API 全量回归通过，沿用逐类独立 JVM 和扩大堆的临时配置；网络协议、文档与分层守门通过，日志 `.smoke/network-packs/final-full-tests.log`。
- 唯一一次 1080p / 2× UI 冒烟通过，多人页、可选包接受页与全部必须页布局均核对；截图 `.smoke/network-packs/film_40.png`、`film_100.png`、`film_160.png`，日志 `smoke.log`。
