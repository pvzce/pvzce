# 礁石海道：整片海上的礁石高地（2026-10-05）

用户要求再想一个能用地形高度游玩的关卡，并点明可以做到海洋。做法是把高度反过来用：
上一关的高地属于玩家（梯田），这一关的高地属于海里的礁石。

- 新关 `yard/minigame/reef_passage.json`：11×6，左端两列码头（唯一的陆地），其余是海；
  海里一道礁石（下坡 + 两列礁顶 + 上坡，0.4 / 0.45）和一道更高的礁石脊（0.85），最右端是出怪的开阔海面。
  四个新场景元素 `pvzce:reef_slope_up` / `reef_slope_down` / `reef_top` / `reef_ridge` 同样用
  `profile` + `art.tiled`（坡面借裸地图集、礁顶借草地），礁顶进 `#c:plantable`、三处坡面进 `#c:unplantable`。
- 高度的用法与梯田相反：礁石正面吃掉低处的平射（礁后水面的僵尸从近侧打不到），礁顶上的泳者又在低处植物的命中带之上，
  只有种在礁顶的植物（0.45，压过下方那道 0.4 的坡）或抛射够得着；再往外那道 0.85 的礁石脊连礁顶的平射也挡住。
- 整片海意味着**只能放会游泳的僵尸**：`rowIsWater` 是逐行判定的，一行里只要有一格水，整行都算水行，
  陆行僵尸没有可落脚的"陆行"（`landRows()` 为空时会原地保留，落在水里就淹死）。所以阵容是
  浮圈三种 + 潜水 + 海豚骑士（潜水在水里平射打不到，得靠爆炸/窝瓜/等它咬植物；海豚会跳过第一株植物），
  水行的小推车按 `MowerData` 的池子配置全换成 `pool_cleaner`；波表因此没有旗子僵尸（陆行）。
- 没有"海洋"背景板：海面走平铺水面（`LiquidFrame.CELL`）铺在内置"未铺草"后院上，
  礁石的岩面就是抬高格子下方露出来的背景裸土。
- 定向验证新增 `ReefPassageTest`（逐列礁石高度、每行都是水行且全行泳池清洁机、礁顶可种而坡面与海面的各自规则、
  海平面平射死在礁上且礁顶泳者打不到、礁顶射手覆盖礁后水面但被高脊挡住、泳者自己翻过两道礁石）；
  一次 1920×1080、2x UI 冒烟胶片 `.smoke/reef/s_*.png` 复核海面、两道礁石与泳者翻礁。真人平衡见 `todo.md`。
