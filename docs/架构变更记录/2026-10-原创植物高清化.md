# 原创植物高清化：贴图像素与棋盘尺寸分开

> 用户指出游戏内贴图可以更清晰，随后确认同时提升所有原创植物。盘点对象为回声铃兰与冰爆菇；
> 原始立绘已有更多细节，损失发生在资源导出阶段。

## 现象 → 定论

**1. 小模型不必配小贴图。** 铃兰正文从 88×88 改为 512×512，冰爆菇的分层画布从 57×81
改为 342×486；两张卡面改为 512×512。UV 使用新的像素范围，世界尺寸、锚点、骨骼与所有
动画关键帧保持原值。资源生成器直接从源图采样，不把旧低清成品放大。

**2. 关联特效一起提高采样密度。** 声波、共鸣环按更高像素密度重新绘制几何；冰弹直接从源图
导出，碎片保留源图裁剪细节。冰爆菇生成器补齐头、身体两份输出，避免复跑脚本还依赖仓库里的旧成品。

## 验证与边界

- JSON 探针仅排除 UV 后与改动前完整相等；模型大小、偏移、骨骼和每条动画轨道没有变化。
- 动画加载与部件拼接测试通过；素材分类检查通过。
- 一次 1920×1080、GUI 缩放 2 的实机冒烟，同时放入两株原创植物，连续拍摄待机、攻击、
  弹丸与共鸣画面。叶子、晶体、脸部细节清晰，落点与层间接缝正常。
  证据：`.smoke/original-plants-hd/frame_480.png` 与同次胶片的 `motion-strip.png`。
- 既有骨架阴影探测仍有目录缺图提示；实机另见 `ice_trap` 粒子路径警告，均记入 `todo.md`。
