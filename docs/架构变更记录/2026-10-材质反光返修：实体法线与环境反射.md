# 材质反光返修：实体法线与环境反射（2026-10-22）

用户指出光线仍不明显、环境缺少反射，并明确实体本身也应反光；确认增强地面与实体法线、保留原画颜色且避免整体油亮。

- `WorldLighting` 的实体法线结合动画部件曲面与平滑 alpha 轮廓，不读取原画亮度作为高度。部件坐标的导数转换法线方向，随动画转动并正确处理镜像 UV；采样限于当前图集矩形内。
  地表保留独立程序高度导数，增强草/土/石的起伏差异；细纹按像素足迹衰减，避免远处闪烁。
- 日月光与局部光共享 GGX 分布、Smith 遮蔽和 Schlick Fresnel 反光计算，按材质粗糙度形成不同宽度的高光；实体也参与该计算。
  增加按反射方向取色的天空/地面半球环境反光与弱地面染色补光，不以整屏亮度代替反射。数值集中在 `PvzceConstants`。
  这是解析环境近似，没有采集场景倒影或追踪实体之间的多次反弹。
- 原「材质高光」参数显示为「高光与环境反射」，沿用配置键、范围与默认值；归零关闭两类反光。材质开关显示为「材质法线与接触阴影」，控制增强法线与接触遮蔽。
  水面共享材质反光，同时遵守水面反射特征位，关闭水面反射后不由新材质路径重新叠加高光。
- 原生 GPU 灰阶对照保留前轮的正午中性、晨昏暖色、月光方向与暗部可读性检查；材质探针分别检查地表起伏、实体轮廓/转动/镜像、无直射时的环境反光、石面与草地的粗糙度差异，以及局部光的反射增量和颜色。
