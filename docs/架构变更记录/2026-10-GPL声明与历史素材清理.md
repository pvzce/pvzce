# GPL 法律声明进游戏、git 历史摘掉原版素材

> 接着上一轮的素材分层做两件收尾：**合规**（GPL-3.0 §5(d) 要求的法律声明）与**仓库体积**
> （重写历史摘掉素材）。素材判决本身见上一节与 `素材对照表.md`，这里只记这两件。

## 现象与根因

- **游戏里只有版本号，没有法律声明**。`PvzceGame.main` 打 `"{} {} starting in {}"`、
  `DebugOverlay` 显示版本——版权行、无担保声明、许可去哪取，三样都没有。GPL-3.0 §5(d) 把
  "Appropriate Legal Notices" 定为有交互界面作品的义务，并且明说图形界面该用 about box。
- **历史里躺着素材，`.git` 283 MB**。上一轮只把 1719 个文件移出**工作区**，`git log` 仍能取出
  它们；另有早期删掉的 `assets/pvzce/font/ui.png`（18 MB × 两份历史版本）从没被清过。

## 定论

**1. 声明文本一处定义、两处显示。** 新增 `PvzceLicense`（`com.pvzce.common`）：`COPYRIGHT`
（`Copyright (C) 2026 crystalneko`）、`STARTUP_NOTICE`（一行）、`ABOUT_TEXT`（"关于"页的全文）。
出口是 `PvzceGame.main` 的一行日志与设置里的**"关于"页**（`AboutScreen`）。启动日志刻意只给
一行：每次启动刷十几行法律文本会被当噪声跳过，比不写更糟；展开的正文在 about box 里。

**2. 版权行没写进 `LICENSE`。** 那是 FSF 的许可原文，一个字节都不该改（末节 "How to Apply
These Terms" 是给使用者抄的模板，填进正文会让许可文件的版本不可辨认）。它落在根 `README.md`
的"许可"一节，代码侧的单一出处是 `PvzceLicense.COPYRIGHT`。

**3. 历史用 `git filter-repo` 全路径清除，不再要那些文件。** 摘掉 `assets/pvzce/animations/`、
`assets/pvzce/sounds/` 与 `font/ui.png` 三条路径的**全部**历史。之所以是全路径而不是"只摘已删的"：
HEAD 里 `assets/pvzce/` 留下的都是自产与二次创作素材（它们在更早的提交里也一直存在），
按路径整棵清除不会误删现在还要的文件。`assets/java/icon.png` **不能删**——`ModInfo` 专门认
id 为 `java` 的内置 mod，那是它的图标。

**4. 新增 `smokeScreen=about` 页键。** 这一页在游戏里要点"设置 → 关于"两次，而它的内容
（法律声明）只有截图才能核对排版：文本长度是合规性的一部分，被截断成省略号就白写了。

## 更正：角色立绘是原创，不是二次创作

**现象**：所有者指出四组角色立绘（`textures/gui/dialogue/`，70 张 / 107 MB）"只是参考了豌豆/蘑菇
的通用形象，并没有直接利用 PvZ 的资源"。我在上一轮把它们归成"二次创作"，理由是"画的是原版的
角色"——**这个理由是错的**：它把"题材像"当成了"衍生"。

**定论**：分类口径定为「**有没有照原版的具体造型**」，不是「题材像不像」。通用植物/真菌形象本身
不是版权客体，正如"画一只蘑菇"不构成对任何蘑菇题材作品的侵权。立绘归**原创**，随 GPL-3.0；
真正属于衍生的只剩复刻原版界面与美术版式的那 23 MB（卡面、图鉴、HUD、标题 logo、关卡缩略图、
场景地面、粒子）。

**落地**：`tools/classify_assets.py` 新增第五类 `ORIGINAL`（原创），`DERIV` 从 332 个 / 130 MB
缩到 262 个 / 23 MB；`docs/素材对照表.md`、`THIRD-PARTY.md` §1/§4、`docs/当前项目架构.md` §2.2
与 `docs/决策记录.md` 同步更正。**这个判断错在方法上**：我按"文件在哪个目录、题材像什么"推断
归属，而正确的做法是问作者——已记进 `踩坑清单.md`。

## 验到了什么

- **重写保真**：第 60 个提交的六个非素材目录（`pvzce-loader`、`pvzce-api`、
  `pvzce-game/src/main/java`、`.../test`、`docs`、`tools`）**树哈希与重写前逐字节一致**，
  只有 `assets/pvzce/` 从 1778 个文件变成 1519 个。提交数守恒：master 112 → 113
  （多的是这一轮的新提交）、wip 分支 17 → 17、`--all` 115 → 116。
- `.git` **283 MB → 177 MB**；`git log --all -- 'assets/pvzce/sounds/music'` 与 `-- '*ui.png'`
  都返回空；工作区 359 个入库素材与 `local-assets/` 1721 个文件都还在。
- `./gradlew :pvzce-game:test :pvzce-api:test` 全绿（1350 例）。
- **冒烟一次，拍了两张图**：`.smoke/license/about-bad.png` 是第一次的结果，
  `.smoke/license/fixed/about.png` 是修好之后的。启动日志里能看到那一行版权声明。
  **这一轮的返工就出在这里**：第一版把声明画在"模糊的标题背景 + 半透明压暗"上，
  白字压在明亮的天空与草坪上几乎读不出来（法律声明读不清等于没显示）。改成铺满整屏的
  不透明深色底（同 `AlmanacScreen` 的写法）后 12 行全文完整、无截断。
- **参考环境（1920×1080 + `gui_scale=2`）没验到**：xvfb 虚拟显示只有 1280×720，
  所以这次是默认环境下看的。按 `冒烟与截图指南.md` §2.3，界面改动"至少要在参考环境里看一次"
  这一条**这轮没满足**；一页纯文本、没有依赖尺寸的排版（只按宽度换行），判断是低风险，但如实记下。
