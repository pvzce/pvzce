# 异能洗牌：种子固定能力与任意实体发射（2026-10-10）

已有孟德尔变异逐发替换豌豆弹，不能表达整局固定的植物能力、产物和任意实体发射。
用户确认新增四关集合，两关传送带、两关自选卡；种子写入关卡文件，重开保持相同结果，
发射物与产物固定到每种植物；射出的真实实体归植物方并保留自身行为，音乐使用 `refer/ms3`。

- `RandomPlantsMechanic` 从已加载植物的能力配置取样，按内容 id、能力类型及规范化配置排序，
  用关卡种子与植物 id 生成级别独立的配方。每种植物获得 1～4 个不同类型的能力，保留原价、
  生命、放置、升级与美术，不修改全局注册表。注册顺序和传送带/自选卡模式不影响配方。
- 注册内容中确定三种持续射手配方，传送带补入缺少的攻击卡；本轮两条实际卡池均有至少三种射手。
  带卡仍免费，自选卡走原付费、冷却和背包筛选路径；自选卡种子选取保证初始豌豆也能持续攻击。
- 发射物和产物从植物、僵尸、资源、投射物注册内容中固定抽取；小推车用现成动画注册为穿透投射物。
  `EntityLaunch` 给所有发射物应用非零速度。真实植物/僵尸保留自身能力，资源仍可拾取，
  非投射物接触敌人造成原射击伤害并落地，投射物保留自己的命中能力。生成数量到限时移除最旧生成物，防止后代堵死攻击。
- 配方通过 `RandomPlantsState` 与通用机制包镜像到客户端，选中植物卡显示能力、发射物、速度及产物。
  资源生产新增带来源植物的接口，天空阳光和僵尸掉落不参加替换。
- 续档重建同一配方并保存速度、剩余路程和队伍；修复随机阳光被普通地面资源丢弃路径误删的问题。
  另修复统一发射运动仍使用抛物目标落地判定、导致高处瓜弹打不中的问题；回归验证覆盖两个真实缺陷。
- 固定模拟随机源、正常付费/带卡消耗与自然收集策略，四关分别在 167、198、263、220 秒通关；
  探针核对种子复现、反序注册、实际花费、实体运动、续档、生成上限及客户端配方同步。
  这些是可行打法证据，真人平衡边界归 `todo.md`。
