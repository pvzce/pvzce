# 2.5K 实体与 UI 高清化：全量覆盖与像素 UV 缩放（2026-10-18）

植物、僵尸的原版骨骼部件多为几十像素，卡面多为 128 方图。用户先要求扩展到实体和 UI，
随后明确其余植物、僵尸也要一起处理；最终覆盖全部植物/僵尸贴图，而非只保留常见种类名单。

- 首批 471 张部件、物品、弹丸、卡面、按钮、HUD 和图鉴框记录在 `tools/upscale_sprites_1440p.json`；
  其余 1155 张植物/僵尸部件记录在 `tools/upscale_remaining_entities_1440p.json`，涵盖变体、受损状态、巨型及 Boss 素材。
  回声铃兰、冰爆菇、共鸣苔的六张已有高密度原创贴图保留原尺寸，不再重复重建。
  两份清单按顺序生成，从各自快照读取；后者的 controller 快照已包含首批部件的密度调整。
- 共用 `tools/upscale_backgrounds_1440p.py` 调用 Upscayl High Fidelity，按原图指纹去重做目录批处理，再缩到 2.5K 显示预算；
  小部件通常为 3 倍、较大部件和卡面通常为 2 倍，最终尺寸以清单为准。
  RGBA 与 LA 的透明通道均从原图重采样，灰度部件保持 LA；世界尺寸、锚点、骨骼、关键帧和事件保持原数据。

  最终 1442 张植物/僵尸 PNG 全部有密度决定，未列明文件为空；遗漏新僵尸素材的负向探针确认会拒绝通过。
  原版部件与 controller 保留在忽略的 `local-assets/`，构建期资源逐字节核对与本机生成结果一致。

  `~/.local/share/pvzce/upscayl-all-entities-1440p-originals/`。
  首批 PNG 从约 3.2 MiB 增至 22.4 MiB，补齐批次从约 4.7 MiB 增至 34.7 MiB。
