# 异能洗牌泳池无尽：随机重开与种子续档（2026-10-12）

用户追加指定泳池无尽每次重新开始使用随机种子。新局与两种重开入口都重新洗牌，
继续正在运行的局或从磁盘恢复时保持原种子、植物能力及固定发射物/产物。

- `RandomPlantsData.randomSeedOnStart` 为可选开关，只有泳池无尽开启；其余关卡保持原有固定种子。
  本局种子和不可变配方共同缓存于机制状态，不修改内容注册表，也不消耗波次与发牌随机流。
  `RandomPlantsState` 下发实际种子，客户端沿用已有能力说明与放置投影。
- `CardSource.Context` 提供运行关卡，让传送带补齐攻击卡时读取本局配方。
  `RandomPlantsMechanic.collectSave` 保存种子；恢复时先重建配方和卡源，再恢复传送带卡片、卡槽与植物能力时钟。
  缺少种子块的旧存档回落到文件原种子，避免继续旧局时重新洗牌。
- 发现 `CompoundTag.getLong` 经 double 读取会损失大整数的低位，改为直接读取 long 标签；跨数值类型的宽松读取保持。
  确定性压缩存档回归覆盖大正种子、负种子、旧档和植物能力配置，以及已发卡片与工具的恢复。
- 真实内存包链路覆盖关卡列表重开、暂停菜单重开、当前局继续及服务器关闭后的磁盘继续；
  定向回归已验证每次重开种子变化、继续配方完全一致、连续无尽和既有固定种子关卡行为。
  本轮没有渲染改动，使用包链路与存档证据；真人多种能力配方的长局平衡仍归 `todo.md`。
