# 能力工坊泳池挑战：生产禁购与更强水陆波次（2026-10-10）

用户要求生产能力不能购买，并增加更难的泳池融合分解关卡；确认采用第四关、30 波、六株初始豌豆、
两片水路莲叶、后半程增强敌人与 1.25 掉落倍率，不额外赠送生产材料。

- `PlantRecipes.canBuy` 是工坊购买资格的唯一判断，生产能力留在配方、库存与掉落池，购买请求由服务端拒绝且不扣款。
  客户端生产材料仍可选取，上方购买位置显示灰色“不可购买”，点击不发购买请求；前三关简介同步说明来源。
- `fusion_4.json` 复用现有泳池背景、液面、六行棋盘与泳池清洁器，加入融合集合末尾，通关第三关后解锁。
  中间两行水域，初始莲叶先放置再承载豌豆；保持零初始阳光、无天空阳光和紫卡免前置规则。
- 新关分五段逐步增强：水路使用救生圈僵尸、路障和铁桶变体，陆路使用普通、路障、铁桶与橄榄球，
  后半程增加潜水与海豚；所有条目显式限定对应水陆行，后半段更密，强度预算高于第三关。
  概率倍率由现有 `FusionData.dropMultiplier` 配置，原三关保持原值。
- 定向测试覆盖四关生产禁购及不扣款、生产材料分解/合成、背包与集合顺序、六行棋盘输入、水路承载、波次地形与强度预算。
  固定种子只补射手/生产者策略在第四关 262.8 秒失败，击杀 41、收集能力 39、自然收阳光 300；未使用复杂配方，真人通关平衡仍归 `todo.md`。
- 唯一一次 1280×720、1 倍 UI 冒烟确认泳池场景、六行防线、泳池清洁器、游泳铁桶与生产禁购标记，
  画面见 `.smoke/fusion-pool/workshop_900.png`。临时世界额外放南瓜且关闭分解损耗用于操作，不改生产关卡。
  配对脚本先点收集会取消铲子选择，故随机加料成功流程仍由自动测试验证，原生补取证项保留；本轮未再次启动冒烟。
