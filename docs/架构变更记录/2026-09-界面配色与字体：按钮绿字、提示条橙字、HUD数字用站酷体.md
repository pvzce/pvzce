> 一轮按原版观感做的调整（不是缺陷修复，记在这里是因为它定下了"哪种东西用什么字/什么颜色"）。

- **两种按钮两种字色**（`components/Button`）：石头灰的 `Style.DEFAULT`（标题页、设置、关卡存档对话框、编辑器各页）
  标签改成**深绿 #1C6B26**，棕色木牌的 `Style.SEED_CHOOSER`（关卡列表页签与底部那排、选卡页）**保持白色**——
  绿字压在棕木上两种颜色会一起糊。禁用态照旧只降 alpha（1 → 0.6），不换色，所以"按不动"与"什么样"是两件事。
- **颜色是照着"实测对比度"定的，不是照着色卡定的**：那些按钮的底板内部是深板岩色（RGB 74,76,109，
  相对亮度 0.078）。第一版深绿 #1C6B26 的渲染实测只有 **1.26:1**，屏幕上就是"深色压深色"，被退回"太暗"；
  中途还试过"深绿 + 粗体 + 浅色描边"来补对比，同样被退：**汉字笔画只有 4~5 像素宽，一圈 2 像素的浅边会把
  字里的空当糊掉**，看着像两个字叠在一起。最终定成 `Button.LABEL_STYLE = TextStyle.bold()` +
  **#4CAF50（实测 2.97:1）**，无描边。要再调只动 `LABEL_R/G/B`：上到 #6BC74A（3.89:1）、
  下到 #43A047（2.50:1）都在可用区间，候选色阶见 `.smoke/analyze/green_candidates_big.png`。

## 按钮标签的字号交给按钮自己算（顺带修掉"字总是偏低"）
- **现象**：同一行按钮里，设置页那种高按钮的字显得很小（标签只占按钮高度的一半），而调用点写的是各自的常数
  （标题页与设置页都写 `scale(1.1F)`，暂停对话框写 `min(1.05, buttonHeight/42)`——同一个问题在三处各猜了一遍）。
  把字号调大之后又发现：字一放大就从**下沿**顶穿按钮，上沿却还空着一大截。
- **定论**：三条规则。
  1. **字号 = 放得下可书写面**：`Button.fittedLabelScale` 取"行盒 ≤ 面高"与"文字宽 ≤ 面宽"的小值 × 调用点倍率，
     再夹在 [0.5, 2.4]；面本身只给标签 `LABEL_SIZE_OF_FACE = 0.75`（0.88 那种填满面的观感是"字要把按钮撑破"，
     低于 0.7 又显得空——这一个数就是整体缩放旋钮）。**"面"是量着美术定的**：石牌（46px 高）面在 8..38 行之间 =
     控件高度的 0.65，两侧 36+35 像素的端帽按高度缩放；木牌是一张整图，边框是 42 行里的 2+5 行。
     第一版按"控件高度的 0.9"填满，直接顶到高光/阴影上（用户截图里"暂停"顶穿边框就是这个），退回。
  2. **垂直位置按墨迹居中**（`Button.labelBaseline`）：汉字墨迹在基线上 0.76em、下 0.05em，行盒却是对称的，
     按行盒居中会让标签整体偏低约 0.14em——字号一大就先从下沿顶出去。
  3. **悬停时标签跟着面板沉**：`button_down_*` 不是"另一块面板"，而是同一块在贴图里下移 1 个原生像素；
     面板沉、文字不沉，就成了"面板从字底下移开"。标签因此下移 `高度 / 46`（字号不动，为 4% 的高度差重光栅不值得）。
     这条没法在本机截图验证（`smokeHover` 需要窗口焦点，平台会忽略指针挪动——见 `冒烟与截图指南.md` §4.5），
     改成 `ButtonLabelScaleTest.theLabelCentresOnTheInkAndSinksWithAPressedPlate` 钉住。
- **粗体第一版做错了，记下来免得再犯**：`FontRenderer` 一开始把同一个 quad **平移一个设备像素再画一遍**
  （右下），这是常见的假粗体做法。在 320×180 的观感下看着还行，但按钮标签是 4~5 像素宽的汉字笔画，
  平移的结果是"两个字叠在一起没对齐"——而且那一遍把**描边也一起平移了**，浅色环变成左边 2px、右下 3px，
  重影更明显。改成**对称膨胀**：借 shader 的描边分支、颜色设成字色，四个方向各外扩一个纹素，最后一遍画，
  压住自己描边的内圈 → 最终是"1 像素浅色边 + 粗一档的字"，advance 不变（粗体不改排版）。
  对比图：`zoom_ghost.png`（旧：平移版，重影 + 环粗细不均）对 `zoom_bold2.png`（新：对称膨胀 + 单圈细边）。
- **提示条的文字是橙黄**（`hud/HintBox`，`TEXT_R/G/B` 由米白改成 **#FFA626**）：原版屏幕下方那句提示就是这个暖色，
  底色（深灰半透 + 一像素亮边）不动。它和"又一条白色标签"的区别，正是"游戏在跟玩家说话"与"界面在报字段"的区别。
- **阳光显示用站酷体**：阳光银行的大数字（`InGameScreen.renderHud`）与每张种子卡印的价格（`SeedCardRenderer`）
  从 `fonts().body()`（思源黑体）改成 `fonts().button()`（站酷快乐体）。两处本来就是原版同一个字体的两处出现，
  而且卡片脚注那个尺寸上站酷的笔画更站得住（代价是同一个 scale 下比思源宽约 14%，两处都验过放得下）。
  截图证据：`small_title.png` / `small_settings.png` / `small_levels.png`（最终：绿色粗体、无描边、字号随按钮
  但只占可书写面的 0.78，边框留边）、`final_btn_zoom.png` 与 `final_pause_zoom.png`（放大看边距）、
  `green_candidates_big.png`（色阶候选）、
  `bold_before_after.png`（假粗体重影 vs 对称膨胀）、`bold_levels.png`（木牌仍是白色无描边，与 `color_levels.png` 逐字节相同）、
  `color_board.png`（站酷数字 + 橙字提示条）、`zoom_bank.png` / `zoom_price4.png`（两处站酷数字）。
