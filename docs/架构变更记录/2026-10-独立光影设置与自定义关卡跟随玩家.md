# 独立光影设置与自定义关卡跟随玩家（2026-10-21）

用户要求独立光影页面、分别控制效果与等级，并确认自定义地形地图及异能洗牌、能力工坊、回声温室跟随玩家设置。

- 新增 `LightingSettingsScreen`，设置中心与视频页均可进入，沿屏幕栈返回；改动即时生效并保存。
  提供总开关、昼夜色调、局部光源与阴影、柔化，以及水面波动、焦散、反射/高光、交互涟漪。
  阴影可关或选低/中/高，水面保留低/中/高；恢复默认只重置光影配置。
- 阴影档位实际切换深度贴图分辨率，柔化控制比较采样半径；关闭局部阴影跳过局部光深度 pass，
  关闭实时阴影仍保留局部照明。水面开关按位移除对应效果，质量档继续限制最高可用特征。
- 新配置默认保留已有表现；昼夜色调关闭保留光源方向，选卡预览同时遵守玩家开关与关卡禁用声明。
  GUI/覆盖层清空全局光源与阴影状态，液体程序重绑时不会重新采到上一局的光源。
- 穿山回廊、礁石海道、梯田山坡、海岛奇兵、潮汐前哨与潮汐堡垒显式声明跟随玩家；
  异能洗牌、能力工坊和回声温室移除强制关闭。原版冒险、解谜等其它关卡的约定保持不变。
- 配置持久化、独立效果位、昼夜中性色、目标关卡策略、横/竖/窄屏布局及按钮交互通过定向回归。
  原生显卡回归验证三档实际纹理尺寸、关闭阴影不关闭照明，以及局部阴影/柔化的真实渲染参数。
- 唯一一次 1080p / 2× UI 冒烟覆盖设置中心、视频入口、光影页档位切换与恢复默认，
  随后进入穿山回廊、礁石海道、梯田山坡、回声温室；日志无 GL 错误。
  `.smoke/lighting-settings/film_500.png` / `film_700.png` 为高档与恢复默认后的页面，
  `controls-tests.log`、`gpu-tests.log` 与 `smoke.log` 保存验证证据。
- 游戏/API 全量测试及文档守门通过；全量使用既有隔离初始化脚本将测试堆临时设为 3 GiB，未改项目构建默认值。
