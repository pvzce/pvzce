# 数据包图标与关卡编辑器按需页签（2026-10-17）

包列表没有作者图标，关卡编辑器无条件铺开常用功能页。现在包根图标贯通工作区与正式包，
编辑器按用户确认的范围保留基础页，其余从首个「关卡」页添加。

- `PvzcePack.ICON_FILE` 统一包根图标文件名；`PvzceResourceManager.packIcon` 直接读取指定包，
  停用包和同名资源包、数据包都独立显示。`PackIcons` 按页面持有纹理，缺失或解码失败回落默认图标，退出释放。
- 工作区「设置」可改名称、选择与移除图标；导入先验证 PNG 再替换草稿。
  构建和旧包导入复制图标，移除后重新构建也会移除正式输出的旧图标。
- `OverviewPage` 管理编辑功能与玩法机制；`EditorModules` 从原有字段和机制识别页面，
  地形、植物、僵尸、信息常驻。添加玩法复用机制 codec 的默认块或现有关卡中的有效模板，
  有声明字段的机制立即生成表单；没有独立页的机制仍列出已启用状态。卡源互斥沿用机制声明。
- 收起仅作用于当前编辑会话，原数据与页面模型保留；保存跳过未启用和不适用的页面，避免注入默认配置。
  页签过多时分页，恢复入口会定位对应导航页。传送带继续隐藏普通卡池页。
- 冒烟发现通用数值表单把缺省值写成范围下限，并将浮点读取成整数。
  `FieldWidgets` 保持缺省数值/布尔为默认状态，只有明确输入才覆盖；数值保留小数精度，输入框与滑块通过回调同步。
- 定向验证覆盖真实添加对话框、空白保存、已有数据识别、收起后保存、动态机制页与默认/小数保真，
  以及停用同名包图标和构建移除图标。唯一一次 1080p/2 倍 UI 冒烟在 `.smoke/pack-modules/`：
  `ui_60.png` 为停用数据包图标，`ui_140.png` 为工作区设置，`ui_260.png` 为基础页，
  `ui_380.png` 与 `ui_500.png` 为添加和收起传送带。数值缺省修正与缺失名称补齐在截图后由定向断言验证，未重复启动。
- `python3 tools/doc_check.py`、文档统计生成和 `:pvzce-game:test` 全量验证通过，日志在 `.smoke/pack-modules/`。
