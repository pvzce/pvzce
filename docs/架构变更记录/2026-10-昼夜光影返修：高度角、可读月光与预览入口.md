# 昼夜光影返修：高度角、可读月光与预览入口（2026-10-21）

用户指出默认白天偏黄发白、像蒙白雾，夜晚缺少月光，植物和僵尸过暗；确认按白天保留原画颜色、夜间有冷色月光且角色清楚的方向修正。进一步要求日月拥有独立色调/强度并随高度角变化，预览按钮仅出现在光影设置页，关卡用 F1 隐藏 UI。

- 原散射对无遮挡射线也累计正亮度，整屏叠加暖色；现在只有沿途部分受遮挡的射线产生光束，无遮挡与全遮挡均无附加散射。
  散射颜色复用日光色，降低基础空气密度；已有的散射强度偏好继续有效，不改写玩家配置。
- 降低日光直射强度并中性化日光和天空色；增强冷色夜间直射与天空填光。颜色及强度常量集中在 `PvzceConstants`，精灵和液体共用。
  实体曲面法线增加朝上的受光分量，让动画片正面可以同时接收天空和日月光，保留左右曲面变化。
- `TimeOfDayLighting.celestial` 统一高度角换算与日月色调/强度：低角度日光及天空较暖、直射较弱，高角度接近中性；月光使用独立冷色与强度。
  循环夜晚的月亮也沿轨迹升落，固定夜关保留高月位置。材质、阴影与日光散射共用这套方向与高度响应，晨昏阴影更长。
- 预览按钮的入口改为已加载关卡的光影设置页，其它设置页和关卡屏不显示。关卡增加可绑定的 `HIDE_UI` 动作，默认为 F1，再按或 Esc 恢复。
  两种纯场景显示复用世界绘制并隔离隐藏控件输入，保留截图键；不改暂停状态，换屏/离关取消。
- 完整 ACES 拟合的暗部趾段会压黑现有素材、中段会抬白；改为中暗部线性保留，高光肩部接连续且单调的 ACES 拟合压缩。
  页面标签明确为「ACES 高光压缩」，保留原配置键和其它调色控制；没有强制重置曝光、伽马或玩家偏好。
- 原生 GPU 灰阶对照复现旧默认：50% 灰色地表被抬至约 77%；新默认约为 54%，夜间约 45%；曲面实体侧部中灰约 46% / 40%。
  定向像素回归覆盖中暗部保真、高光单调性、正午日光中性、低角度暖光、月光高度/方向与夜间可读性，以及散射无底雾、局部出现、全遮挡消失和强度上限。
  昼夜色调关闭时也去除新增晨昏材质染色，保留高度响应；像素检查钉住这一开关行为。
  导航/输入检查验证预览仅在光影页可用、F1 绑定及关卡限定、隐藏控件不发包、恢复原屏和离关清理。
- 唯一一次 1080p / 2× UI 冒烟使用显式启用光影的隔离 9×5 昼夜场景，包含植物、僵尸、路灯花、火炬与真实阴影；
  胶片 `.smoke/natural-lighting/film_400.png` / `film_1000.png` 为昼/夜默认，`film_600.png` / `film_1200.png` 为相应关闭光影对照，日志无 GL 错误。
  冒烟后降低散射密度，并补入高度角渲染、按钮范围和 F1；最终版本通过原生 GPU 与定向输入回归复核，未重复启动游戏，胶片不作为这些追加改动的画面证据。
