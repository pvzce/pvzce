# 单体实体属性与小僵尸关卡迁移（2026-10-05）

用户指出 3-5 为数值和缩放差异注册整族 `mini_*` 内容造成重复，要求可以注册 attribute 并给单个实体添加。

- `BuiltInRegistries.ATTRIBUTES` 注册数值属性定义；每个服务端实体持有独立基值与具名修饰器，支持加算、基值乘算、总值乘算和移除修饰。完整语义见实体架构册「单体数值属性」。
- 接入最大生命、绘制倍率与僵尸的移速、啃咬伤害/间隔、护甲耐久倍率；波次条目、僵尸定义和预放置实体可声明初值。植物的预放置属性在放置钩子与首次生成包之前生效。
- 3-5 的波表从生成器改用普通内容 id 加属性；移除七份小僵尸定义、图鉴条目与语言生成分支。保留原有平衡和判定盒；旧存档的实体和待出怪队列经现行 3-5 数据迁移，不重新注册旧 id。
- 属性基值与持久修饰器、待出怪属性和蹦极货物属性进存档；客户端经 `EntityAttributesS2C` 接收计算结果，生成/重同步发完整快照，变更即时发布。断臂、破损护甲、Boss 阶段和冰锥读取实例数值。
- 波次编辑器保存条目未提供控件的字段，覆盖 `attributes`、行、通路与生命增长；计数编辑不会擦掉单体差异。
- 定向验证覆盖独立实例、修饰器/存档、实际移动和啃咬、生成与运行时镜像、旧队列续档、装备状态、协议及编辑器保存。一次 1280×720 冒烟在同一棋盘呈现普通/半尺寸的普通僵尸、路障僵尸与豌豆射手，证据 `.smoke/entity-attributes/s_400.png`。更广的属性迁移及编辑 UI 边界见 `todo.md`。
