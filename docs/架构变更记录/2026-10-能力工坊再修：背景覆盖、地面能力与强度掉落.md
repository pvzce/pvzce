# 能力工坊再修：背景覆盖、地面能力与强度掉落（2026-10-09）

上下工作栏把中间草坪按两个轴拉伸，植物铲除立即入库，僵尸又一律低概率只给一份，操作与收益都缺少变化。
用户允许 UI 覆盖不妨碍种植、观察的背景，确认保留点击/批量收集，并指定各关通过一个参数调整掉落概率。

- `FusionLayout` 改为上方能力库存与购买、右侧合成/待种/手持区、底边提示；复用原有木框和卡面。
  `LevelStage.fitReference` 与 `PvzceCamera` 保持背景和格子的原比例，工坊覆盖右侧背景，所有格子可见可点击。
- `FusionCardSource` 保留一张普通铲子工具槽，界面只改卡条的位置；选取、拖动、右键取消、快捷键与一次使用后放回
  都走 `InGameScreen` 的普通路径。无动画控制器的工具光标复用卡槽图标，避免默认实体贴图路径失配。
- 铲除植物经既有损耗后，在原位置散开掉落每份能力；库存只在收集时增加，未收集能力照常永久保存、同步与读档。
  教程明确增加“先收集再加料”，首次铲除仍无损。未种/手持种子卡的分解保留直接回收至库存。
- `FusionDrops` 根据僵尸定义的强度预算分档，初始本体生命与护甲耐久之和提升档位，概率与数量只有 `PvzceConstants` 一处。
  一次抽取互斥数量；普通、路障、铁桶按用户给定表，更强两档按确认方案递增。`FusionData.dropMultiplier`
  统一缩放正数量概率，总和超过 100% 时等比例归一化；三关显式采用 1.0，编辑器可调，协议与黄金样包同步更新。
- 验证覆盖真实界面点击、一次铲除后收起、逐个收集、教程、存档/线上状态、互斥概率与倍率、强敌散落及多种窗口比例；橄榄球与巨人高于铁桶档，通用全关卡模拟也先收集再加料。
  固定种子真服务端模拟：首关 240.9 秒胜利，击杀 25、收集能力 11；第二关 326.4 秒胜利，击杀 56、收集能力 27；
  第三关 267.8 秒失败，击杀 24、收集能力 16。策略只补射手/生产者，不注入阳光，真人平衡见 `todo.md`。
  唯一一次 1920×1080、2x UI 冒烟 `.smoke/fusion-overlay/workshop_*.png` 走通原生按住选铲、铲除、地面收集、
  加料、合成、右侧取卡与重新种植；镜头无草坪拉伸。之后修正光标兜底图标路径与方向提示，未再次启动冒烟。
