# 多人选卡返修：主动同步与准备流程（2026-10-29）

现象：合作客人点击“选卡并准备”没有反应。入口缺少关卡列表时只显示等待，既不发请求也不在数据到达后继续；房主选关后也未刷新客人的档案与卡池。

- 点击后主动请求房间当前关卡列表，收到响应后自动打开原选卡页；房主尚未选关、响应缺少所选关卡均显示明确原因。
- 房主选关后，先按当前房主世界向已加入客人同步档案和卡池，再发布新关卡；房主切关关闭旧选卡页，取消旧准备请求，退出房间后的迟到响应不再打开选卡；断线清掉等待状态，同关卡重连可再次准备。
- 回归覆盖真实 TCP 上的实际按钮点击、选一张卡、提交卡组、客人“已准备”和房主开始后进入战场；另验首次列表缺失、切关取消、名单更新保留选卡页、房主换世界后档案更新。
- 定向回归与游戏/API 全量回归通过（全量使用逐类独立 JVM、扩大堆配置），日志 `.smoke/multiplayer-preparation/regression.log`、`full-tests.log`。唯一一次客户端截图冒烟被临时测试服与 Fabric 游戏进程的模组清单差异拒绝，未获得有效联机场景截图；未再次启动游戏，不能将其记为画面通过。
