# 实时光影：动画深度阴影与局部遮挡（2026-10-20）

用户要求真正的光影，认可当前动画生成阴影贴图、日月光与局部光源计算遮挡、实体接收阴影的方案。

- `WorldShadows` 用深度纹理数组保存日月光和已有局部光源的光空间深度；骨骼、破损装备、南瓜前后层、
  后备精灵与不透明地形共用当前绘制几何，不再用静态整身图压扁来代表启用光影后的实体。
- 日月光采用平行投影，局部光采用透视投影；透光轮廓按贴图与顶点 alpha 裁剪，加法辉光不挡光。
  主光分为环境与直射部分，遮挡只移除直射；局部光按材质底色和可见性贡献，停止把光照直接加成白色斑块。
- 主精灵与液体共享深度比较和 PCF；接收平面梯度同时修正采样点与硬件比较过滤的偏移，避免实体自遮挡。
  抬高顶面与封口参与遮挡；已画进背景的隐藏地表按原背景 UV、实际高度重采样接收光照，不新增素材。
- 阴影资源延迟分配并在关闭时释放；阴影 pass 恢复 FBO、视口、裁剪、混合、深度测试与深度写入。
  GUI、覆盖层退出世界阴影状态。玩家关闭或关卡强制禁用着色器时仍走既有静态阴影与水面降级路径。
- 这是一条基于竖直动画片与高度场的 2.5D 实时阴影链路；未增加实体三维模型、材质法线或全局光照。
- 原生显卡像素回归验证主光/局部光遮挡、自阴影偏移、抬高接收面、透明/加法部件和 GUI 隔离；
  精灵与液体 GLSL 均经过实际驱动链接。渲染定向回归及文档守门通过；游戏与 API 全量测试通过。
  全量加载语言资源时默认测试堆不足，本次用 `.smoke/real-shadows/test-memory.gradle` 临时将测试堆设为 3 GiB 后完成，未改项目配置。
- 唯一一次 1080p / 2× UI 冒烟覆盖昼夜草坪、泳池、屋顶及关卡禁用着色器；
  `.smoke/real-shadows/film_*.png` 含开场横幅，主体与地表仍可检查，日志无 GL 错误。
  该展示场景稳定阶段约 120 fps、世界渲染约 1–2 ms，不作为满棋盘压力结论。
  冒烟后发现的背景坡面接收偏移已改为按真实地表重采样，并由原生抬高接收面的像素断言复核；未重复启动冒烟。
