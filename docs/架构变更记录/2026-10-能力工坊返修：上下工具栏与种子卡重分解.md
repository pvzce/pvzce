# 能力工坊返修：上下工具栏与种子卡重分解（2026-10-09）

首版工作台与游戏材质不协调，控件全挤在底部，合成到暂时无法种植的卡也不能回收。
用户进一步要求上下分布并消除四周留白，最终采用原有木框、纸卡与工具槽环绕完整草坪。

- 上栏放阳光、分解铲、能力库存和购买，下栏放合成区、待种卡与手持预览；数量用独立木质标签显示。
  `FusionLayout` 共用绘制与点击几何，小窗口按原生暂停/倍速控件的剩余宽度分页；卡片取出与分解分开点击。
- 未种卡与手持卡都能重分解，也可用分解铲直接点击卡片。服务端按真实实体校验并消费，清除手持引用，
  植物与卡片共用能力恢复逻辑；卡片始终按 20% 概率随机损失一份能力，教程没有无损例外。
  重复、过期、外队伍和已结束请求拒绝；分解教学卡后回到加料步骤，可重新完成教学。
- 上下木栏铺到窗口边缘；中间 `LevelStage.fill` 完整铺满背景，棋盘按相同两个轴换算，实体保持原比例。
  所有草坪格子仍可见可点击，没有背景侧边留白；相机缓存和败北镜头同时保留上下空间。
- 定向验证覆盖回收、手持清除、损耗边界、教程恢复、非法请求、工具栏点击与相机几何；协议语义与黄金样包同步更新。
  1920×1080、2 倍 UI 的操作胶片验证购买、合成、待种卡回收、手持卡回收与铲子点卡，
  追加消除留白的画面见 `.smoke/fusion-ui-fill/workshop_1020.png`。截图用测试命令补充阳光以操作购买，关卡初始经济未改。
