# 能力工坊追加修正：紫卡免前置与面板外移（2026-10-10）

融合得到的紫卡仍要求对应底植物，右侧面板又离最后一列过近，妨碍直接使用合成结果与观察。
用户确认三关统一免前置、保留格子占用和玉米两格占地；面板外移自身宽度约四分之一，允许整体轻微等比缩小。

- `PlantPlacement.Ctx.upgradesWithoutBases` 默认关闭，服务端与客户端在融合机制下开启；
  `PlantPlacement.requiresUpgradeBase` 统一控制放置分支、升级锚点和前置消费。
  紫卡按一般地形、叠放、占用与完整占地检查直接种植，植物定义、紫卡标识和配方保留。
- 玉米加农炮从点击格向右占两格，预览与落点一致；邻近玉米投手不会吸走锚点或被消费。
  猫尾草可以直接在草坪上种植并完成首关教学。普通关卡仍检查和消费前置植物。
- `FusionLayout.WORKSHOP_SHIFT` 统一平移右侧矩形与文字，参考宽度随右侧空间扩展；
  相机与控件共用等比缩放，所有控件留在窗口内，草坪与右侧背景之间留出观察空间。
- 定向验证覆盖八种紫卡在三关中的真实取卡/种植、普通关卡前置要求、占用、两格越界、邻近基座、预览与多种窗口比例。
  固定种子的既有补射手/生产者模拟结果保持一致；它没有使用紫卡组合，真人平衡继续见 `todo.md`。
  唯一一次 1920×1080、2x UI 冒烟 `.smoke/fusion-direct/workshop_*.png` 经原生按住购买，走通猫尾草和玉米加农炮的
  购买能力、加料、合成、右侧取卡与直接种植；最终图中末列猫尾草、玉米加农炮和铁桶僵尸均可完整观察。
  取证档案只拥有这两张植物卡，并在临时数据包中提供 100 阳光和一只铁桶僵尸，正式关卡经济与波表未改。
