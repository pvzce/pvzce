# 能力工坊组合材料：南瓜防御承载与玉米投掷爆炸（2026-10-10）

专属能力直接充当合成材料，使南瓜头与玉米炮各自独占一种材料，既难复用又分散随机掉落。
用户确认先复用现有材料：南瓜头由防御与承载合成，玉米炮由投手与爆炸合成；植物实际行为保留。

- `PlantRecipes.components` 是组合行为向材料展开的唯一规则；完整配方仍排序、保留重复份数并忽略参数。
  合成、植物/卡片分解、购买列表和僵尸掉落共用该规则，不新建材料注册表。服务端拒绝购买旧专属材料且不扣阳光。
  每份材料价格与关卡概率倍率保持原值；两种植物各消耗两份材料，分解仍按一次操作最多损失一份。
- `shell` 与 `cob_cannon` 保留行为注册ID、Codec、叠放、瞄准、装填和占地规则，只退出工坊材料池。
  变异换卡继续共用完整配方，南瓜不会换成单独防御或承载植物，玉米炮不会换成普通投手或炸弹。
- 旧工坊库存、合成区与未收集掉落在读档时展开；重叠库存累加，合成区超额材料返库。
  地面材料原地散开、第一份保留原编号，新增编号先避开全部旧掉落；再次保存读取不重复展开或发放材料。
- 行为验证覆盖真实回收—加料—合成—种植—铲除—收集、非法购买、掉落池、旧档转换、合成区容量和变异角色保持。

  取证见 `.smoke/fusion-materials/workshop_470.png` 与 `workshop_1370.png`。临时世界补充初始阳光用于购买，生产关卡初始经济未改。
