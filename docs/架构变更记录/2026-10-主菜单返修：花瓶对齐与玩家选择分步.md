# 主菜单返修：花瓶对齐与玩家选择分步（2026-10-17）

用户指出数据包石牌倾斜、设置与退出没有落在花瓶正面，玩家选择对话框拥挤且常驻名字输入框。
用户确认改为名单选择、新建输入和删除确认三个步骤，创建后仍由「确定」切换。

- 内置 image_gen 将数据包石牌与文字调平；更新双倍原生尺寸贴图与水平牌面命中。
  对右侧场景贴图做坐标网格探针，测得左花瓶正面约为源图 x=490..565/y=440..475，
  右花瓶正面约为 x=640..695/y=455..490，加场景原点 (71,41) 后放置设置和退出，
  缩小文字使整块按钮落在瓶身内。探针在 `.smoke/title-repair/vase-coordinate-probe.png`。
- `PlayerPickerDialog` 扩大名单区域，只保留新玩家、删除选中、确定和取消。
  新建独立模态输入名字并选择全解锁；成功后返回列表、高亮并滚动到新玩家，
  不改变当前玩家，按确定才切换；删除经过既有确认对话框，取消不删除。
- 创建使用原子目录创建，空名、非法名字和重名在表单内反馈，重名不发送重建档案包。
  名字继续遵循 `WorldPaths` 的既有目录规则；创建包后请求原当前玩家的档案，
  避免新玩家档案响应临时留在旧玩家的菜单状态。取消新建不创建目录或发送创建包。
- 名单只绘制完整行，滚动上限也按完整可见行计算；修复非整行视口到不了最后一个玩家的边界。
- 窗口缩放重排两个表单并保留未提交名字及全解锁选择；关闭输入弹窗移除对话框，释放文字焦点。
  标题页名字、版本与消息绘制在模态遮罩后面，弹窗存在时不叠加服务器菜单消息；
  当前玩家目录不存在时木牌显示选择提示。
- 定向回归覆盖独立输入、创建/取消、空名/重名、全解锁保留、长名单定位、显式切换、
  删除确认/取消、控件边界和缩放。唯一一次 1080p / 2 倍 UI 冒烟位于 `.smoke/title-repair/`：
  `ui_80.png` 为主菜单，`ui_160.png` 为无输入框名单，`ui_240.png` 为创建表单，
  `ui_320.png` 为新玩家高亮，`ui_400.png` 为删除确认，`ui_560.png` 为确认切换后的木牌，
  `ui_640.png` 为实际点击设置花瓶，`ui_800.png` 为数据包水平石牌入口。
- 长名单最后一行的滚动边界在截图后由真实列表回归补验，未重复启动冒烟。
