# 内容菜单视觉统一：商店、数据包与创意工坊（2026-10-18）

用户指出商店、数据包和创意工坊的观感粗糙，关卡页相对协调。截图确认问题集中于鲜艳背景与内容争抢视线、
木框与灰紫按钮混搭、同权重工具栏，以及商品灰块图标和列表说明被裁切。

- `MenuPageCanvas` 共用关卡菜单的安静背景、棕色细框内容板与木质按钮；画布仍为 800×600，主菜单原版场景映射保持原契约。
  `AbstractSelectionList` 的暖色选中态与 `EditBox` 的浅纸色输入框按页面选择，默认风格保持原契约。
- 商店初始选中第一件商品，列表只展示图标、名称、类别和价格，完整说明在详情栏换行；卡槽扩展复用种子包图标并标出 +1。
  购买按钮随金币和持有状态更新，仍由服务端决定交易。列表行高随画布缩放，购买按钮留在详情栏的内边距内。
- 数据包列表使用同一套暖色选中态；内容摘要复用既有内容类型译名，作者图标缺省时显示纸签。
- 工坊将新建、导入与构建按用途分开，类型筛选移到下栏；选择全部类型同时清空查询和筛选。
  卡片显示预览、名称和内容摘要，悬停时用内部 ID 替换摘要；无封面内容使用有类别文字的纸签。
  属性编辑的分组使用独立页签和选中标记，操作按钮、输入框和预览区共用暖色材质。
- GUI 定向回归及跨尺寸商品选择/购买回归通过；唯一一次跨页冒烟在 `.smoke/ui-polish/`，按 1920×1080、2 倍 UI 配置，
  `page_140.png`/`page_220.png` 为商品详情和切换，`page_300.png` 为数据包，`page_380.png`/`page_460.png` 为工坊首页和工作区，
  `page_540.png` 为属性编辑。截图后仅收齐购买按钮内边距，并以边界断言校验，未重复启动。
