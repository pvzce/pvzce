# 启动器账号交接：游戏侧消费、验证与离线（2026-10-19）

启动器已有登录交接 v1，游戏既不消费短码，也不处理公开启动参数中的敏感值；后端接口尚未部署。
本轮完成游戏侧，契约以 [PVZCELauncher 固定提交的说明](https://github.com/pvzce/PVZCELauncher/blob/e6c9b64b6c501a290ef838724f59eb50060db245/docs/PVZCE_GAME_LOGIN.md) 为准。

- `GameLoginArguments` 在 Fabric 的普通参数解析前消费 API origin 与短码；分离/等号形式、重复、缺值均处理，
  支持合法短码以 `--` 开头。异常参数只产生普通离线状态，不请求网络。公开参数的 true/false 两路与可变参数表均不保留这两个参数。
  原始参数数组及 JVM 启动命令属性同步脱敏；在敏感 HTTP 初始化之前关掉 JDK HTTP/TLS wire diagnostics 与非幂等重试开关。
- `PvzceGameProvider` 只在游戏自有启动边界跨类加载器传递 origin、可擦除短码缓冲与无效标记，不改 Fabric fork 的第三方实现。
  入口立即转给 `GameAccount`，缓冲擦除；短码/游戏令牌不进入配置、存档、本地玩家或游戏内包协议。
- `GameAccount` 在单独 daemon 工作者中按顺序兑换、GET 验证，再发布已登录状态。限定游戏会话权限、有效期限与身份一致性；
  定时复验、到期、撤销、网络失败均清掉身份。手动退出立即离线并请求服务端退出；取消或验证失败后获得的令牌也尽力撤销。
  退出游戏的撤销为有超时的后台尽力请求，不延迟进程退出；服务器未确认退出时 UI 明确提示，令牌不在本地保留或重试。
- `GameLoginHttp` 仅访问已验证的同一 origin，HTTPS 为常规要求；HTTP 只开放启动器列明的本机/模拟器地址。
  不带网站 Cookie/CSRF，不使用全局 Cookie/认证器/代理，不跟随重定向；响应大小、整次请求和连接均有限制。
  任意响应正文、异常原因与凭证均不进入 UI/日志，UI 只显示本地状态与经过校验的服务端用户名。
- 主菜单展示交接状态；设置新增「启动器账号」→ `AccountScreen`，展示验证后用户名与到期时间、提供退出/取消和返回。
  本地玩家选择与存档归属保持独立；离线不妨碍游戏。账号页标题按截图中的浅背景改为深色。
- Loader 参数测试、真实本地 HTTP 测试和独立 JVM 的 wire diagnostics 探针通过：包括两种参数形式、身份/权限/期限校验、
  Cookie 隔离、错误状态、跨站重定向、丢响应不重试、过大/畸形/停滞响应、取消期间状态不复活和周期撤销。
  唯一一次游戏冒烟经真实 Knot 入口从网络失败进入离线，再从设置点击进入账号页；
  `.smoke/game-login/ui_60.png`、`ui_120.png`、`ui_180.png` 分别为主菜单、设置与账号页，日志与实例配置检索无测试凭证。
  标题色在这次截图后收齐，未重复启动。
- API、Loader、游戏全量测试与 shadow 打包通过，文档守门及 `tools/doc_check.py` 通过。
  默认测试堆在资源枚举/语言加载处耗尽；以 `.smoke/game-login/test-heap.gradle` 临时设置测试堆 2 GiB 后全量通过，
  日志为 `.smoke/game-login/full-test-2g.log`，未修改项目构建默认堆。产物确认包含账号类且不含能力声明。
- **能力声明仍不打包**：真实账号、后端原子单次兑换、重放、封禁/退出撤销及跨仓库集成尚无测试部署可验。
