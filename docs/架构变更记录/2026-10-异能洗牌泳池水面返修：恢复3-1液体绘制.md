# 异能洗牌泳池水面返修：恢复3-1液体绘制（2026-10-11）

用户指出泳池水面错误，指定与3-1相同。两个异能泳池关已有相同背景、水格与液体素材，
但关卡级 `disable_shaders=true` 把正常液体绘制关闭，水面走了预烘焙降级帧。

- `random_plants_belt_3.json` 与 `random_plants_belt_endless.json` 都改为 `disable_shaders=false`，
  使用3-1的既有液体绘制与玩家画质设置，不另造水面素材。
- `PoolAreaLevelsTest.thePoolUsesThePoolBackdropWithTheLiquidPassOn` 扩至两个异能泳池关，
  比较3-1的背景与水格，并验证服务端发给客户端的配置保持液体绘制开启。
- 唯一一次1920×1080、2倍UI原生冒烟核对连续水纹、漂移焦散与泳池承载植物，
  帧带见 `.smoke/random-pool-water/pool_600.png` 到 `pool_1500.png`，日志确认18个水格进入液体绘制。
- 上一轮检查了泳池棋盘与叠种，却没有比较参照关的渲染开关；泳池背景相同不足以证明水面相同。
  本轮把参照关的显示配置加入既有泳池回归检查，防止复制草坪关配置时再次关闭水面。
