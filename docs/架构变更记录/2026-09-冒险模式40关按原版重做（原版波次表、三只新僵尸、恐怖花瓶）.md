# 冒险模式 40 关按原版重做（原版波次表、三只新僵尸、恐怖花瓶）

> 需求与用户逐条拍板的取舍见 `决策记录.md` Q16~Q25。以下按“原版数据 → 关卡 → 引擎 → 顺带修掉的”累积。

## 冒险模式 40 关按原版重做，并补上三只原版僵尸

- **需求**（用户报）：3-6 ~ 4-10"相较于原版出现了或多或少甚至完全的偏差"，要求用网络查原版关卡信息后重做；
  追问后用户拍板：**范围扩到 40 关**、缺的三只僵尸全补、3-10 做成原版 mini-boss、4-10 发卷心菜投手、
  波次"掷一次定死写成固定表"、mini-boss 密度用原版点数 ×3、节奏用原版 1800/2500/4500、
  1-6/1-7 改成原版固定满卡组、迷雾起点列用原版 6/5/4、雪橇小队按原版做全、1-10 保留"一分钟后入夜"、
  4-4 的花瓶关按原版搬到 4-5（三回合）、2-5 打地鼠按原版（8 波、僵尸全从墓碑来）。

- **原版数据出处**：PvZ-Portable（原版反编译）里的四张表 + 一个循环，全部落进
  `tools/original_levels.py`（唯一出处，逐条注明来自哪个函数）：
  `gZombieWaves`（每关波数）、`gZombieDefs`（点数 / 首现关 / 首发波 / 权重）、
  `gZombieAllowedLevels`（每关允许的僵尸）、`Board::PickZombieWaves`（波次生成），
  外加 `LawnApp::GetAwardSeedForLevel`（发卡链）、`Board::LeftFogColumn`（迷雾起点列）、
  `Board::AddGraveStones`（夜关墓碑数）、`PickBackground`/`StageIsNight`（布景与昼夜）、
  `PickZombieWaves` 里的 mini-boss / 小僵尸 / 保龄球三处特例。

- **40 关全部重生成**（`tools/write_adventure_levels.py`，取代原来按世界分的四个脚本）：
  波数、旗帜位置（每 10 波一面）、点数预算（波序号/3+1，旗帜波 ×2.5 再补 min(点数,8) 普通僵尸 + 旗帜）、
  每关允许的僵尸池、新僵尸固定在第 N/2 波与末波（矿工/气球是第 7 波与末波）、末波必须含本关所有种类、
  余下点数按权重抽；行分配照原版 `RowCanHaveZombieType`（水里只放会游泳的，陆地僵尸第 6 波起可以下水，
  落成 ducky 形态）；间隔 1800 / 2500+随机 0~600 / 旗帜波后 4500，旗帜波给 750 tick 预警。
- 由此修掉的实际偏差（举其大者）：世界 3/4 不再出现报纸/铁门/舞王（原版一次都不发），
  橄榄球只在 4-2、撑杆只在 3-9、潜水只在 3-7 与 3-10、海豚只在 3-8/3-9/3-10/4-4、
  气球只在 4-3/4-4/4-9、矿工只在 4-6/4-7；巨人从世界 3/4 全部撤掉（原版 5-8 才首现）；
  3-10 从"选卡 + 巨人压轴"改成原版的 mini-boss 关（传送带 + 点数 ×3 + 开局 100 tick 出怪）。
- **发卡链回到原版**：3-10 海蘑菇、4-1 路灯花、4-2 仙人掌、4-3 三叶草、4-5 分裂豌豆、4-6 杨桃、
  4-7 南瓜、4-8 磁力菇、4-10 卷心菜投手；原版"什么都不发"的八关仍由本项目的四个工具与四个增益填
  （1-4 手套 / 1-9 自动收集 / 2-4 锤子 / 2-9 蘑菇射程 / 3-4 水壶 / 3-9 水草蔓延 / 4-4 花瓶工具 / 4-9 迷雾退缩）。
- **世界 4 是夜**（原版 `StageIsNight` 含 `BACKGROUND_4_FOG`）：十关的天降阳光关掉、音乐换成原版雾曲
  `rigor_mormist`（素材里一直没人引用）；迷雾起点列改成原版三档 6 / 5 / 4（4-5 是原版唯一不在这条曲线上的
  关：`PickBackground` 把它送回夜草坪，所以它没有雾、五行、没有水）。
- **三个 mini-boss 关**（1-10 / 2-10 / 3-10）的"密"改用原版写法：波次表本身点数 ×3，去掉 1-10/2-10 原来的
  `zombie_spawn_speed_multiplier: 2.0`。
- **1-6 / 1-7 不再发选卡页**：原版第一次冒险第 8 关才有选卡页（`ChooseSeedsOnCurrentLevel`），
  1-1 ~ 1-7 的卡槽按解锁顺序发满。
- **2-5 打地鼠按原版**：8 波、波次不带走路僵尸（全部由 `grave_spawner` 从九座墓碑里冒出来）、
  开局 0 阳光、卡槽三张（土豆雷 / 墓碑吞噬者 / 樱桃炸弹）、音乐 loon_boon。
- **4-5 恐怖花瓶（新机制 `pvzce:scary_potter`）**：夜草坪、无波次、无小推车、只有一个卡槽（樱桃炸弹）与锤子；
  三个回合（花瓶分别撒在第 6-8 / 5-8 / 4-8 列），瓶里装植物卡或僵尸，第二、三回合各有 2、3 只绿叶瓶
  （原版 `ScaryPotterChangePotType`）；砸光所有瓶且场上无僵尸就进下一回合，最后一回合清空即通关
  （`LevelServer.declareVictory` —— 0 波的关卡永远等不到"波次出完"，胜负必须由机制自己说）。
  花瓶美术取自原版 `Scary_Pot.png`（`tools/gen_scary_pots.py` 切出问号瓶与绿叶瓶两种，128×128 与别的场景贴图同规格）。
- **三只缺的原版僵尸**（用户点名的三只，`refer/anim` 里的原版 reanim 一直都在）：
  - `pvzce:bobsled_zombie` 雪橇小队：一只实体 = 一只雪橇 + 三只随从（原版 `NUM_BOBSLED_FOLLOWERS`），
    雪橇本身 300 点"头盔"，被打坏后四只一起变成普通走路僵尸；只在有冰的行里生成，
    场上没有冰时波次改出四只普通僵尸（原版 `CanAddBobSled` 的兜底）。
  - `pvzce:jack_in_the_box_zombie` 玩偶匣：引信是**走过的距离**（原版 `450 + Rand(300)` px ≈ 6.5 格，
    这里取中值不掷骰），走满距离后开盒 110 tick，然后炸掉半径内的植物与僵尸（含自己，且不给掉落）。
  - `pvzce:pogo_zombie` 跳跳：`pvzce:bounce` 是 `pvzce:vault` 的循环版（同一套滞空窗口与位移，
    没有第二份实现），每 80 tick 一次，落地就找下一株植物跳过去；遇到高坚果会折断弹簧、从此当普通僵尸走。
- **顺带修掉的**：
  - 3-5 的小僵尸缺 `mini_ducky_tube_conehead_zombie`（原版水池里的小路障僵尸），补上定义与图鉴条目。
  - 迷雾退缩增益（4-9 发）现在作用在原版起点列上，4-10 的雾因此比 4-9 更靠右，而不是"原版那样的后退一步"。
  - `ZombieSpawnSpeedTest` 里"1-10/2-10 出怪速度 ×2"的断言随规则一并删掉（改成"没有冒险关再用这个规则"）。

- **用户玩过之后报的三条，都是一个根因的三张脸**：
  1. **花瓶关不该能选植物**。4-5 原来只有一张固定卡（樱桃炸弹）却没写 `max_seed_slots`，于是"总卡槽 8 − 固定卡 1 > 0"→ 选卡页照常出现，玩家能把花瓶工具和别的植物带进来。定论：**卡面填满自己的槽**（`max_seed_slots: 1`）——"没什么可挑"的唯一判据是 `总槽数 − 固定卡数 ≤ 0`，2-5 用的也是这一条；砸出来的卡走 `CardSource.receiveCard` 追加，不受这个上限约束。
  2. **"很多花瓶是空的"**：`useVase`（玩家的花瓶工具）**只问了格子里有没有植物**，于是它可以"覆盖"——点坟墓会把墓碑盖掉，点恐怖花瓶会把那只瓶变成一只**空花瓶**（`pvzce:vase`），而瓶子里的内容还留在机制的账上：草坪上再也没有可砸的瓶，这一关永远打不完，玩家看到的就是"一堆空花瓶"。定论：**花瓶只能放在裸地上**（草/裸地/屋顶两式，且没有植物），别的都算"已经有东西了"；另外加了一次自愈（`recoverLostPots`）——账上还有、草坪上已经没了的瓶子会被重新立起来，被植物占住的则从账上划掉，免得旧存档永远卡住。
  3. **"锤子只能砸花瓶不能砸僵尸"**：`applyToolEffect` 的锤子分支在瓶子那一格 `yield` 得太早——砸瓶与打僵尸成了二选一，站在瓶子旁边的僵尸因此挨不到那一下。定论：**一次挥击两件事都做**（先开瓶，再按 `range` 打范围内的僵尸）。
- 顺带：瓶子的摆放改成**可复现**的（按关卡 id + 回合号播种），因为客户端拿到的那块开局棋盘是另一个临时关卡（`LevelServer.openingBoard`）造的——两边的洗牌不同，画出来的瓶子就会与服务器上的不是同一批。
- **验证**：`OriginalAdventureLevelsTest`（新）把原版四张表**抄进测试**再独立复算一遍：
  40 关的波数、旗帜位置、每波只用本关允许的僵尸、末波含全部允许种类、新僵尸出现的位置、
  发卡链、布景/昼夜/高度/迷雾列/传送带/初始阳光；另有 4-5 的 `ScaryPotterTest`、
  三只新僵尸的 `BobsledJackPogoTest`，以及一批按新事实更新的旧用例。
  一次冒烟拍了 4-5 的开局棋盘并摆上三只新僵尸（图见 `.smoke/original40/`）。
