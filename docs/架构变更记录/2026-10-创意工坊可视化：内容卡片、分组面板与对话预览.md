# 创意工坊可视化：内容卡片、分组面板与对话预览（2026-10-16）

用户指出工坊等同于图形化 JSON 编辑器，确认改为常用内容的可视化创作入口。

- 工作区内容与选择器采用卡片网格，植物、僵尸、弹丸、资源和卡槽显示游戏内预览与名称；
  草稿语言覆盖参与名称与搜索，技术 ID 留作次要信息。贴图可看缩略图，素材支持右键预览或试听。
- `WorkshopPresentation` 管理私有内容目录、工作区素材覆盖与有界动画池，退出恢复素材覆盖；
  定义的未保存参数通过正式 codec 更新私有目录，不注册到游戏目录。刷新文件版本后重建浏览卡片。
  `EntityPreview` 的缓存键带实体种类，避免不同注册表同名内容复用错误形象。
- `WorkshopJsonScreen` 默认使用分组面板：基本、消耗与放置、能力、外观与动画、声音按内容种类呈现。
  数字/文字直接输入，布尔使用开关，内容引用从卡片选择；能力用卡片组合，弹丸发射项可从弹丸库添加。
  高级属性与 JSON 仍保留，未编辑字段原样保存；无效数字不会默默保存为先前的值。
- 动画页直接播放当前草稿，支持选择动作、暂停、循环配置和图片帧缩略图排序；每帧可调整秒数，
  排序和删除同时维护逐帧时长；小窗口使用紧凑帧行。内嵌片段字段定位到原始子树，避免点击后误进入根字段。
- 对话页新增角色/表情缩略图及真实播放入口，角色定义可预览左右两侧对话框。
  `DialoguePreviewScreen` 复用 `DialogueOverlay` 的立绘、选项与语音，ESC 或返回按钮回到原编辑器；
  对话脚本接受私有目录，能预览尚未构建的角色。
- 1080p / 2 倍 UI 单次冒烟经过工作区、植物面板、能力卡、动画帧、对话页与实际播放，
  胶片在 `.smoke/workshop-visual/`。截图发现亮背景降低表单标签对比，随后加入统一深色遮罩；
  补正后使用定向回归与全量测试验证，按约定没有第二次冒烟。未保存预览的注册表冻结问题也由回归发现并修正。
