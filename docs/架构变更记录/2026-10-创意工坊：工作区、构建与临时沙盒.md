# 创意工坊：工作区、构建与临时沙盒（2026-10-15）

关卡编辑器直接写入已加载的数据包，实体与素材也没有统一创作入口。现在标题页进入创意工坊，
每个工作区独立保存草稿，构建才产出正式数据包。

- `Workspace` 把名称与命名空间分开；草稿在游戏目录的 `workspaces/`，不参与包扫描。
  构建先校验，再暂存、替换 `datapacks/workshop-<工作区目录>/`；失败保留旧输出，首次启用，更新保留启停状态。
  来源标记防止覆盖同名手工数据包。旧 `user_levels` 可以复制导入，原包由玩家自行停用。
- `WorkshopContent` 复用正式加载器与标签加载器，在独立注册表副本中校验与提供草稿目录。
  副本只继承代码注册项，再从当前包栈重建动态内容，不保留已移除包的内容或原注册表的回调订阅。
  所有现有数据定义目录都有模板复制、逐项属性/数组编辑和高级 JSON；音频、贴图与动画支持文件导入。
  植物模板复制放置标签，工具与僵尸创建对应卡槽；名称写入工作区语言文件。
- `EntityCapability` 共用实例/存档契约，`CapabilityHost` 提供实体服务。
  射击、生产、爆炸、护甲、伴舞召唤可跨植物/僵尸使用；旧僵尸射击格式委托同一个射击实现。
  同种能力的多个实例按次序分别保存时钟，防止多资源生产组合续档后互相覆盖。
  其它能力仍按所需的移动、格位或装备条件分开注册，没有虚构一个可执行任意组合的宿主。
- `AnimationBindings` 加入动作到片段的对应表；工坊支持绑定动画文件与片段、骨骼动画导入预览，
  以及帧图片排序、逐帧秒数、循环和播放结束设置。完整骨骼关键帧制作按用户确认的 B 档暂缓。
  音效事件、清单和缓存保留命名空间，清单接受字符串和对象两种音频条目。
- 测试使用 `WorkshopSessionC2S` / `WorkshopSessionS2C` 确认服务端覆盖层加载完成后再刷新客户端素材。
  `WorldStore` 的临时全解锁档案不落盘，入场也不写世界目录或会话锁；退出恢复正式内容、档案和悬置的编辑屏幕栈。
- 定向验证覆盖构建失败保留旧包、停用状态、标签循环、真实控件点击、跨宿主能力、片段绑定、音频命名空间和包链路恢复。
  唯一一次 1080p/2 倍 UI 冒烟在 `.smoke/workshop/`，菜单到工坊走实际按钮分发。
  截图暴露动画预览视口用了顶端坐标；改成窗口内的正方形底端视口，并用小窗口/常用尺寸边界断言验证，按单次启动约定未重拍。
