> 对应目标：assets 分类整理、`data/pvzce/pvzce` 扁平化、粒子系统数据驱动、用 `refer/anim` 扩充植物。
> 验证：`./gradlew :pvzce-game:test` — **339 个用例，0 失败**；编辑器画布与关卡冒烟截图已人工核对。

## 1. assets 分类整理（完成）

内容 id **没有改**。分类只改目录，动画目录由内容 JSON 的 `animation_dir` 字段声明，缺省仍按 id 路径（mod 不用写任何新字段）。

```
assets/pvzce/textures/entities/
├─ plant/{attacker,producer,defense,environment,special}/<id>/*.png
├─ zombie/{basic,armored,special,underground,giant,boss}/<id>/*.png
├─ projectile/<id>.png     ← pea、butter
├─ resource/<id>/|.png     ← sun、三枚硬币、钻石、钱袋
└─ tool/<id>.png           ← glove、shovel

assets/pvzce/animations/
├─ plant/<类目>/<id>.json   zombie/<类目>/<id>.json   resource/<id>.json
```

契约改动（都是"可覆盖的默认值"）：

| 位置 | 改动 |
|---|---|
| `PlantDef` / `ZombieDef` / `ProjectileDef` / `ResourceDef` / `ToolDef` | 新增可选 `texture` |
| `AnimationBindings` | 新增可选 `animation_dir`（嵌入五个定义的同一个 flat map codec） |
| `EntityArt`（新增，`common/core`） | **"这个 id 用哪份美术"的唯一答案**：`animationFile` 与 `sprite` 两个问题一次查表 |
| `EntityTextures` | 转发给 `EntityArt.sprite`（路径不再能从 id 推出来） |
| `AnimationManager` | 动画文件路径改走 `bindings.fileId(defId)` |

工具：`tools/group_entity_assets.py`（幂等迁移脚本）、`tools/reanim_to_pvzce_all.py` 的 `EntityConfig.group`（重新生成美术时落在正确类目）。

### 顺带修掉的三个生成器真实缺陷

1. `render_controller_icons.py` 按模型定义顺序绘制而不是按部件的 `z` 排序 → 前叶盖住头，三线/分裂/机枪/双发的卡面只剩一片叶子。
2. 同一 reanim 把"仅身体"（`anim_idle`）与"带头"（`anim_head_idle`）分成两段：机枪射手与分裂豌豆用前者会渲染出没有头的植物。
3. 三线射手的三个头**可见区间互斥**（4–41 / 45–82 / 86–123），任何单帧区间都只能显示一个头 —— 原版靠三条时间线同时画。新增 `force_visible`（按 clip 强制可见）与 `exclude_track_regex`（同一张贴图背多个逻辑部件时按 track 名筛选，四个炮管就是一张图）两个配置项解决。

## 8. 盘点：保留但尚未接线的素材

一轮清理把"没人用的东西"分成两类，处理方式**不同**，所以在这里点名，免得下一轮把它们当垃圾删掉：

| 类别 | 判据 | 处理 |
|---|---|---|
| **重复名字** | 同一个 ogg/贴图有**两个事件**，其中一个没有任何引用，而另一个被引用 | **删**（见下） |
| **保留素材** | 素材对应的**功能**还没做，因此谁都还没引用它 | **留**，并在本表登记 |

已经按第一条删掉的：11 个"音乐的第二个名字"（`sfx/misc/{crazy_dave,grasswalk,loon_boon,moongrains,ultimate_battle,zen_garden}`、`sfx/ambient/choose_your_seeds`、`sfx/ui/{lose,losemusic,win,winmusic}`）—— ogg 全留着，它们由 `music/` 下那个活着的名字引用。详见 `架构变更记录.md`。

按第二条保留的：

- **三首还没用上的关卡曲**：`music/cerebrawl`、`music/graze_the_roof`、`music/rigor_mormist` —— 原版对应还没做的那几关，事件与文件都在，等关卡写出来直接用。（`music/watery_graves` 已挂在 3-1 ~ 3-4，`music/loon_boon` 挂在 3-5，见 §9。）
- **约 136 个没有播放点的音效事件**（僵尸各类低吼/惨叫/气球/蹦极/潜水、疯狂戴夫的十几条语音 `sfx/misc/crazydave*`、`sfx/misc/sukhbir*`、UI 的 `sfx/ui/{achievement,bleep,chime,slotmachine,...}`）：原版音效库已经整批转换并注册（`sounds.json` + `data/pvzce/sound_events/`），对应的僵尸/关卡行为做到哪一步就接哪一步。**不要**因为"没有调用点"删它们 —— 这是内容词汇表，不是死代码。
- **`pvzce:redstone` 与 `pvzce:energy_bean`**：资源定义（`data/pvzce/resources/`）、常量（`PvzceIds.REDSTONE`/`ENERGY_BEAN`）、图标与实体贴图（含 `textures/resource/*_2.png` 第二帧）都在，功能未实现。`PvzceIds` 里因此有两个"全仓库没有引用"的常量，是**有意**的。
- **`animations/tool/hammer.json` + `textures/entities/tool/hammer/{1,2,3}.png`**：锤子作为卡（`data/pvzce/tools/hammer.json`）已经能用，但 `ToolDef` **按设计不带动画**（工具没有自己的 `AnimationBindings`），所以这份已转换的挥锤动画没有任何加载点 —— 巨人僵尸的 `hammer` clip 是另一份，在 `animations/zombie/giant/gargantuar.json` 里。等工具获得动画支持时接上。
- **粒子**：145 个定义**全部**有引用（这轮核对过），没有保留项。

同一轮实测的两个数字，供下次盘点对照：`sounds.json` 189 个事件 ↔ 180 个 ogg 文件，**双向零孤儿**（每个事件都有文件，每个文件都被事件引用）；内置 18 个关卡全部通过 `LevelValidator`（`BuiltInLevelsValidateTest`）。
