> 对应目标：assets 分类整理、`data/pvzce/pvzce` 扁平化、粒子系统数据驱动、用 `refer/anim` 扩充植物。
> 验证：`./gradlew :pvzce-game:test` — **339 个用例，0 失败**；编辑器画布与关卡冒烟截图已人工核对。

## 1. assets 分类整理（完成）

内容 id **没有改**。分类只改目录，动画目录由内容 JSON 的 `animation_dir` 字段声明，缺省仍按 id 路径（mod 不用写任何新字段）。

```
assets/pvzce/textures/entities/
├─ plant/{attacker,producer,defense,environment,special}/<id>/*.png
├─ zombie/{basic,armored,special,underground,giant,boss}/<id>/*.png
├─ projectile/<id>.png     ← pea、butter
├─ resource/<id>/|.png     ← sun、三枚硬币、钻石、钱袋
└─ tool/<id>.png           ← glove、shovel

assets/pvzce/animations/
├─ plant/<类目>/<id>.json   zombie/<类目>/<id>.json   resource/<id>.json
```

契约改动（都是"可覆盖的默认值"）：

| 位置 | 改动 |
|---|---|
| `PlantDef` / `ZombieDef` / `ProjectileDef` / `ResourceDef` / `ToolDef` | 新增可选 `texture` |
| `AnimationBindings` | 新增可选 `animation_dir`（嵌入五个定义的同一个 flat map codec） |
| `EntityArt`（新增，`common/core`） | **"这个 id 用哪份美术"的唯一答案**：`animationFile` 与 `sprite` 两个问题一次查表 |
| `EntityTextures` | 转发给 `EntityArt.sprite`（路径不再能从 id 推出来） |
| `AnimationManager` | 动画文件路径改走 `bindings.fileId(defId)` |

工具：`tools/group_entity_assets.py`（幂等迁移脚本）、`tools/reanim_to_pvzce_all.py` 的 `EntityConfig.group`（重新生成美术时落在正确类目）。

### 顺带修掉的三个生成器真实缺陷

1. `render_controller_icons.py` 按模型定义顺序绘制而不是按部件的 `z` 排序 → 前叶盖住头，三线/分裂/机枪/双发的卡面只剩一片叶子。
2. 同一 reanim 把"仅身体"（`anim_idle`）与"带头"（`anim_head_idle`）分成两段：机枪射手与分裂豌豆用前者会渲染出没有头的植物。
3. 三线射手的三个头**可见区间互斥**（4–41 / 45–82 / 86–123），任何单帧区间都只能显示一个头 —— 原版靠三条时间线同时画。新增 `force_visible`（按 clip 强制可见）与 `exclude_track_regex`（同一张贴图背多个逻辑部件时按 track 名筛选，四个炮管就是一张图）两个配置项解决。
