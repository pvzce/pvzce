# 素材对照表

> **这份表回答一件事**：`pvzce-game/src/main/resources/assets/pvzce/` 下的素材，版权分别归谁。
> 它由 `tools/classify_assets.py` 生成（改分类就改那个脚本，别手改本表），
> 判决依据是**文件谱系**——谁生成了它——不是文件名。

## 1. 怎么判的

靠文件名猜不出来。三个反直觉的实例，都验过：

| 素材 | 看起来 | 实际 | 怎么验的 |
|---|---|---|---|
| `entities/plant/defense/giant_nut/` | 像自建内容 | **原版素材** | 与 `wall_nut/body.png` 的 sha256 完全相同（`1947cf1e…`） |
| `entities/plant/defense/explosive_nut/` | 像原版 | **二次创作** | 原版坚果改色，形体与线稿一致但字节不同 |
| `tools/gen_scary_pots.py` | 像个自产脚本 | 读的是 `refer/im7/images/Scary_Pot.png` | **脚本名不代表产出是原创** |
| `textures/gui/dialogue/` | 像"原版角色的拟人化" | **作者原创设计**，只是题材用了通用植物形象 | **看目录名与题材都推不出归属，得问作者**（这条是我的判断错了一次，见 §2 末） |

所以判决只认三条谱系证据：`tools/reanim_to_pvzce_all.py` 的 83 条实体配置（原版 reanim 转换）、
`tools/gen_*.py` / `tools/make_*.py` 的输出路径、以及 sha256 去重（707 个文件是同一张图被多处复用，
这是原版"零件图集"的指纹）。

## 2. 六类归属

| 分类 | 含义 | 处理 |
|---|---|---|
| **原版素材** | 从 `refer/` 转换或直接搬运的原版文件，版权归 PopCap/EA | **移出仓库**，留本地 `local-assets/` |
| **二次创作** | 复刻原版的界面与美术版式，或把原版素材改色/拼合；法律上是衍生作品 | 所有者拍板：**保留在仓库**（边界见 §4） |
| **原创** | 作者自己画的，**没有**照原版的具体造型 | 随 GPL-3.0 分发 |
| **自产** | 程序生成或手绘的通用图形，不涉及任何角色形象 | 随 GPL-3.0 分发 |
| **第三方开源** | 四份 SIL OFL-1.1 字体 | 随仓库分发，须附许可原文（已附 `font/OFL*.txt`） |
| **非官方音乐** | 用户指定的本地音乐，明确不属于官方音乐 | 单列来源；作者与许可未提供，不推定属于 GPL 或第三方开源 |

**"二次创作"与"原创"的分界**是"有没有照原版的具体造型"，不是"题材像不像"：
四组角色立绘（`textures/gui/dialogue/`，70 张 / 107 MB）画的是豌豆、蘑菇这类**通用**植物与真菌
形象的拟人角色，发型、服装、配色、性格都是作者自己的设计，因此归**原创**；
而卡面、图鉴、标题 logo、关卡缩略图复刻的是**原版的界面与美术版式**，归**二次创作**。
所有者 2026-09 明确过这个口径，原先那句"角色为原版植物的拟人化"是我按文件所在目录推断的，不准。

## 4. 边界说明（重要）

**二次创作仍是衍生作品，"保留"是项目所有者的取舍，不是法律结论。**
EA 的官方内容政策禁止 `game revivals, fan games, or community-run servers`，也禁止
`obtain assets through "data mining"`（原文与出处见[报告](报告/PvZ开源项目的许可证与版权素材处理调研.md)
与 `../THIRD-PARTY.md` §4）。把复刻原版版式的 UI、按原版形象重画的卡面留在仓库里，
**降低的是"直接再分发原版文件"这一条，并不消除"用其 IP 做替代版本"这一条。**
要彻底规避，得连这一半也移出去。

**原版素材的去向**：`tools/exclude_pvz_assets.py` 把它们移到仓库根的 `local-assets/`
（由 `.gitignore` 排除），并在那里生成 `pack.mcmeta`。本地构建由 `pvzce-game/build.gradle`
里新增的构建期任务把它作为独立 classpath 根接回去，所以 `run` / `test` / 冒烟照常带素材跑；
`local-assets/` 不存在时（例如刚 clone）任务自动跳过，游戏仍能启动，缺贴图处方显示为棋盘格。

**可复查**：`python3 tools/classify_assets.py --check` 会在出现未归类素材时退出码 1；
`--dry-run` 可以预览 `exclude_pvz_assets.py` 要动哪些文件。
