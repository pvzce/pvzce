## 4. 顺手修掉的既有缺陷（都是过程中被测试或冒烟照出来的）

| 现象 | 根因 |
|---|---|
| 路灯花的灯收不回来 | `PlantCapability.onRemoved` 从存在那天起就没有被派发过 |
| 僵尸不开枪 | 弹丸只查僵尸目标（`findTarget` 只看 `enemiesInRow`），僵尸需要"打植物"的另一半 |
| 铲植物反而清空阳光 | 光铲退款用了 `putResource`（**设**）而不是 `addResource`（**加**） |
| 炸弹只有 1 点伤害 | `DeathBlastCapability` 构造器把"没写"的哨兵 0 夹成了 1 |
| 增益变动变异偶尔什么都不做 | 变动幅度小于 1 时"往一个方向移动"是空操作，没有兜底反向 |
| 种一株水草长出八株 | 增益的钩子挂在 `spawnPlant`（扩散自己也走它），改挂到落卡路径 |
| 同一条变异出现两次时，先到的那份还在生效 | "正在行动"的集合按 **id** 记，两条同 id 条目互相冒充 |
| 变异自己发的包全部丢掉 | `send` 走的是"环境 bridge"，只在玩家动作/命令处理期间存在；命令是排队执行的 |
| 淹水草坪在泳池盘上什么也不做 | 泳池的中间两行本来就是水；改成"没水的行里最靠中间的两行" |
| 草坪上多出来的水格画不出来 | `pvzce:water` 是**液体**元素（整片水面按水池框一次画完），逐格水位需要另一种元素 |
| `rowIsWater` 只认 `pvzce:water` 这个 id | 地形性质的问题应该问 `surfaceClass()` |
| 定时台词在第二关会全部立刻播完 | 客户端只有跨关卡连续的全局 tick，没有"关卡自己的 tick" |
| 花瓶工具选中后光标是空的 | `animation_dir: tool` 指向一个没人写过的动画文件（缺文件是静默的） |
| 4-4 的花瓶…… | 见 `架构变更记录.md` 的批次 7 一节（塞卡路径、搬运时的复制、放回原格被自己挡住） |

## 7. 数据包 / 资源包页面（第 11 批）

- **入口在标题页**（用户指定），标题页因此是六个按钮：开始游戏 / 商店 / 数据包 / 模组列表 / 设置 / 退出。
- **能看**：左列表分三段（内置 / 资源包 / 数据包），每行显示启用状态、名字与文件数；
  右详情显示种类、目录、`pack.mcmeta` 的描述，以及按注册表目录统计的条目数
  （内置包今天的数字：关卡 44、植物 41、僵尸 32、动画 78、声音 180…）。
- **能管**：启用/禁用写进 `config/pvzce-packs.json`，然后请求服务端重载、等回执、客户端再重载内容
  —— **顺序不能反**（关卡定义与注册表是服务端推过来的）。**内置包不能禁用**，点了会被拒。
- **顺手修的可见性问题**：标题页多了一行"服务端最近一条消息，显示 5 秒"。
  此前服务端在菜单里拒绝一个请求时只发一条消息，而菜单没有任何显示通道，玩家的感受是"点了没反应"。
  同一个分支里还发现 `-Dpvzce.traceMessages=true` 会让游戏内提示全部消失（消息只进日志、不进关卡）。
- **没做**（记进 `todo.md`）：`.zip` 形式的包、`pack.mcmeta` 的依赖与 `pack_format` 校验、
  世界级数据包目录（`saves/<world>/datapacks`）。
